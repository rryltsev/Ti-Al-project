Репозиторий содержит данные для точного восстановления 22 обученных моделей GRACE. Для каждой модели восстанавливаются TensorFlow SavedModel, финальный checkpoint и `model.yaml`. Набор включает семь запусков с полной подгонкой и пятнадцать с ограниченными масками. В [индексе](grace-final-models.csv) перечислены все 198 исходных файлов, их размеры, пути относительно `/home6/u3129/tial-fm-research/` и SHA-256, заново прочитанные с UMT. Хеши также совпадают с сохранёнными протоколами завершения четырёх расчётных серий.

Сжатые отличия весов, графы TensorFlow и метаданные занимают в Git 113 746 206 байт. Один раз потребуется базовая модель GRACE-2L-OMAT-medium-base-fp64. Она доступна в Hugging Face по зафиксированной ревизии `4aff666029967745f7993f348eb87a804d625cff`. Скрипт сверяет SHA-256 архива, базового checkpoint и каждого восстановленного файла. Для восстановления достаточно файлов репозитория и базового checkpoint. ## Восстановление из чистого клона

Команды выполняются в корне репозитория. Нужен Python 3.10 или новее. На этапе восстановления используется стандартная библиотека.

Чтобы взять и базовый файл из этого же GitHub-репозитория, загрузите один архив из релиза и передайте его восстановителю. В нём сохранены исходный data shard, его происхождение и полный текст ASL.

```sh
python tools/release_assets.py --get --name grace-base-fp64-recovery.zip
python tools/restore_grace_models.py --case PBE-restricted_radial-N694-seed10 --base downloads/grace-base-fp64-recovery.zip
```

Базу также можно получить напрямую у авторов. Список доступных вариантов и команда для загрузки закреплённой копии из Hugging Face приведены ниже.

```sh
python tools/restore_grace_models.py --list
python tools/restore_grace_models.py --case PBE-restricted_radial-N694-seed10 --download-base
```

Укажите `--case` несколько раз для нескольких моделей. Флаг `--all` выбирает все 22. Исходный архив базовой модели весит 211 681 882 байта. Скрипт сохраняет его в `tmp/grace-base/` и поддерживает докачку при поддержке диапазонов сервером. Распакованный базовый файл имеет размер 174 132 878 байт и SHA-256 `b0edbae73335e32b55e8bb64c7f4fe3cac4d5b01ea277dc5db1ac61a0d1231e5`. Кэш можно перенести на другой компьютер либо назначить через `--cache`.

Если базовый checkpoint или исходный архив уже есть, передайте его путь. Пример восстановления всего набора на машине без сети использует относительный путь к уже полученной базе.

```sh
python tools/restore_grace_models.py --all --base tmp/grace-base/checkpoint.data-00000-of-00001 --output tmp/grace-models
```

Полный набор занимает 7,22 ГиБ без учёта кэша. Дерево внутри `--output` повторяет каталоги UMT. Например, каталог `grace-pbe-n694-20261110-01/cases/PBE-restricted_radial-N694-seed10/seed/10/final_model/` содержит граф, переменные и метаданные экспорта. Рядом с каталогом `seed/` находится `final-checkpoint/`. Скрипт сверяет файлы, оставшиеся от предыдущего запуска, и достраивает недостающие. ## Состав серий

| Набор | Функционал | Маски | Seed | Моделей |
|---|---|---|---|---:|
| N200 | PBE | `full`, `restricted`, `restricted_mlp`, `restricted_radial` | 10, 20, 30 | 12 |
| N200 | r2SCAN | `full`, `restricted`, `restricted_mlp`, `restricted_radial` | 10 | 4 |
| N694 | PBE | `full`, `restricted_radial` | 10, 20, 30 | 6 |

Для каждой модели в `research/grace-final/<case>.zip` лежат граф, индексы, служебные записи и описание расположения тензоров. В `weights/grace-weights-<case>.zip` сохранены обратимые побайтовые отличия от закреплённой базовой модели. Скрипт обращает перестановку байтов и XOR, затем собирает оба двоичных файла весов в исходном порядке. SHA-256 проверяет весь результат, включая служебные записи TensorFlow.

Для 14 расчётов можно восстановить состояние Adam рядом с финальными весами. Команды, охват по seed и исходные контрольные суммы приведены в [инструкции по восстановлению оптимизаторов](grace-optimizers.md).
