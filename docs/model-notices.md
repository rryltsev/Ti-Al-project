# Происхождение весов

**DPA4-Neo.** Базовый чекпойнт проекта — DPA4-Neo-OMat24-v20260805 от DeepModeling Community. Обучение на данных Ti–Al, выбор шага и экспорт выполнены в этом проекте. DPA4-OMat24 и производные веса распространяются с указанием авторства по CC BY-NC 4.0. Ссылки для цитирования приведены в карточке модели. [Исходная модель и авторы](https://huggingface.co/deepmodelingcommunity/DPA4-OMat24) · [лицензия](licenses/DPA4-CC-BY-NC-4.0.txt).

**GRACE.** Базовая модель — GRACE-2L-OMAT-medium-base-fp64 от AMS, ICAMS, Ruhr University Bochum. Архив весов зафиксирован в ревизии 4aff666029967745f7993f348eb87a804d625cff по SHA-256 `763b7e5679c81ea82d39e595e701d0c9f6565064393f705cbe76663c9583d0aa`. Варианты Ti–Al получены дообучением в ноябре 2026 г., конкретные даты, маски, seed и конфигурации есть в каталогах серий. Производные веса GRACE распространяются по Academic Software Licence для академического некоммерческого использования, без гарантии. Код, разбиения, входы и инструкции обучения хранятся в исследовательской части репозитория. [Карточка исходной модели](https://huggingface.co/AMS-ICAMS-RUB/grace-foundation-models) · [условия ASL](licenses/GRACE-ASL.md) · [код и воспроизведение](research.md).
