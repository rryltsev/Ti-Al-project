# Test50, фононы α-Ti и проверка свойств жидкого сплава

## Test50 и финальные ошибки

В замороженном наборе 50 геометрий и 11 698 атомов. Из них 25 геометрий взяты из жидкого архива, 8 из hcp-, 9 из bcc- и 8 из γ-TiAl-траекторий. Для каждой структуры сохранены POSCAR, идентификатор, состав и исходная траектория или архив. Отбор, геометрические допуски и результаты проверки на совпадения описаны в [паспорте набора](../testset/TiAl-test50-v1/README.txt). Повторяющихся геометрий с проверенными обучающими данными не найдено. Часть твёрдых кадров происходит из тех же траекторий, что и обучающие кадры. Пересечение с предобучением DPA4 неизвестно.

В итоговый парный расчёт вошли 49 геометрий, для каждой есть три DFT-метки. Жидкую TiAl-test-025 исключили после отмены ожидающего задания r2SCAN. Остановка последовала после просмотра результатов. Контрольную точку PBE меняли с 5k на 15k и затем на 20k также после промежуточных просмотров. Для статьи важно сохранить фактическое покрытие и историю выбора. [Срез n49](../testset/monitor/results/n49-f94a64dc4d95bca4/metrics.json) · [Закрытие серии](../testset/monitor/runs/early-stop-20261104/closure.json) · [Хронология](../testset/monitor/README.txt)

Расчёт сопоставляет исходные энергии VASP TOTEN с энергиями моделей. Компоненты сил объединены по всем атомам, интервалы в полной таблице оценены бутстрепом по структурам. Исходные E/F, геометрии и статусы хранятся в [снимке DFT](../testset/monitor/data/latest.json), идентичность моделей и прогнозов задают [реестр моделей](../testset/monitor/model_registry.json) и [манифест 300 прогнозов](../testset/monitor/prediction-manifest.json). В числе прогнозов есть архивные PBE 5k/15k и общий предобученный DPA4-Neo. Хеши и исходную ревизию этой базовой модели содержит [реестр предобучения](../testset/monitor/pretrained_registry.json).

Из корня клона следующая команда проверяет хеши коллекции и воспроизводит MAE и RMSE по энергиям и силам для всех трёх функций и обоих типов моделей. Достаточно Python 3.10 или новее со стандартной библиотекой.

```console
python testset/verify_archived_metrics.py
```

Для пересборки рисунков и бутстреп-интервалов в отдельной рабочей копии установите зависимости из файла ниже. Анализ читает локальные прогнозы и перезаписывает текущие рисунки в `monitor/results`. Параметр `--with-alignment` сохраняет отдельный вариант в `results/article-aligned` с фиксированными поправками, оценёнными на обучении.

```console
python -m pip install -r testset/monitor/requirements-lock.txt
python testset/monitor/analyze.py
```

## Фононы α-Ti

Для PBE, PBEsol и r2SCAN сравнивались DFT и DPA4 на одинаковых для каждой пары геометриях, в сверхъячейке 4×4×3. Смещения составляют ±0,01 Å. Применены центральная разность сил, акустическое правило сумм, сетка Γ 50³ и уширение DOS 0,05 ТГц. Площадь DOS равна 3 на атом. Вариант рисунка с шестью панелями использует PBE 15k, PBEsol 23100 и r2SCAN 23200. Каталог включает дисперсии, DOS, экспериментальные точки, силовые константы во входных массивах, инструкции и код пересборки. [Рисунок 2 и данные](../phonons/results/figure2-six-panels-20261101-02/) · [Журнал этапов и параметров](../phonons/README.txt)

При сравнении пяти контрольных точек минимальные относительные расхождения DOS и RMSE отсортированных частот вдоль Γ–K–M–Γ–A получены у PBEsol 15k (0,254 ТГц) и r2SCAN 10k (0,240 ТГц). У PBE по L1 DOS из 5k, 15k, 20k лидирует 15k. Ранжирование относится к этой решётке, набору параметров и наблюдаемой величине. В журнале отдельно отмечены открытые проверки сходимости DFT, размера ячейки и эталонных напряжений. Архивные журналы отражают состояние на указанную в них дату. ## Численные архивы и новые расчёты

Вложения выпуска предназначены для локального восстановления объёмных материалов. В `tial-md-and-audit-arrays.zip` сохранены относительные пути от корня клона, включая ASE/LAMMPS-траектории, ряды напряжений, массивы геометрий и DFT-меток для аудита, силовые константы и промежуточные результаты. Внутренний `validation-archive-index.json` перечисляет размер и SHA-256 каждого файла. Чтобы восстановить выбранную папку, распакуйте её с сохранением путей в корень клона.

`tial-test50-historical-cpu-exports.zip` хранит экспортированные модели первоначальной CPU-проверки (PBE 5k, PBEsol, r2SCAN). Результат Test50 с PBE 20k получен исторически из оригинального чекпойнта; сравнение по уже сохранённым прогнозам полностью локальное. Для **нового** многократного DPA4-инференса выполните freeze с `DP_TRITON_INFER=2` и сверьте на тех же структурах энергии, силы и напряжения с исходным чекпойнтом. Используйте прошедший проверку `.pt2` для дальнейшей оценки, фононов и MD. Перед новым расчётом UMT согласуйте учётную запись для этой серии.

`grace-pbe-n694-optimizer-states.zip` содержит шесть отдельных состояний TensorFlow для возобновления обучения GRACE PBE N694 (full и restricted_radial, seed 10/20/30). Имена внутри совпадают с исходной структурой каталогов на UMT. Манифест описывает также 36 массивов электронного рестарта VASP, оставшихся в исходном локальном архиве `offloaded-vasp-restarts-and-grace-optimizers.tar.gz` размером 2 434 914 859 байт. Его SHA-256 указан в [квитанции резервирования](../audit/storage-20261114/summary.json), контрольные суммы отдельных файлов и относительные пути приведены в [исходном манифесте](../audit/storage-20261114/offload-manifest.json). При повторении VASP-расчётов PAW-наборы берут из лицензированной установки и сверяют с метаданными расчёта.
