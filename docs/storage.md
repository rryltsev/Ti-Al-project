Численные результаты, по которым удобно выбирать следующую задачу, собраны в [оглавлении проекта](../README.md). Исходные конфигурации и версии моделей различаются между сериями. При воспроизведении начинайте с руководства по конкретной серии.

| Нужные данные | Где их взять |
|---|---|
| Рукопись, таблицы статьи и данные рисунков | `manuscript/` и `deliverables/`; [карта редакций и рисунков](research.md) |
| Предсказания Test50, исходные DFT-метки и правила подсчёта | `testset/`; [метрики и проверка](validation.md) |
| Модели DPA4 | Три чекпойнта статьи лежат в `legacy/article-training/models/`. Для 24 запусков full/LoRA есть [объединённые веса](research-dpa4-checkpoints.csv) и [исходные чекпойнты с оптимизатором и номером шага](dpa4-training-restarts.csv). |
| Данные FM train/validation и массивы отдельных запусков | Наборы исследования перечислены командой `python tools/restore_research.py --list`. Для выбранной серии используйте `--data` и префикс из списка. [Команды](research.md) |
| 22 финальные модели GRACE | Сохранены индексы, графы и отличия тензоров от зафиксированной базовой модели. Одна базовая модель подходит для всех случаев. [Восстановление весов](grace-final-models.md) · [Состояния Adam для 14 запусков](grace-optimizers.md) |
| Данные кластерного разложения и границы фаз | `phase_reproduction/`; [C46, МС и прямой MTP](phase-reproduction.md). Сводные таблицы и код находятся рядом с результатами. Крупные оконные ряды и фононные силы перечислены в [индексе сырых данных](../phase_reproduction/raw_files.csv). |
| Архивы исходного проекта Desktop | `legacy/`; [карта VASP, MACE, MD и проверки комплектности](legacy-source.md). Поиск по пути и контрольной сумме выполняется в [индексе архивов](../legacy/archive-index.csv). |

## Выборочная загрузка

Каталог описывает исходный файл, его размер и SHA-256. Для составного вложения он также задаёт порядок, теги и контрольные суммы частей на GitHub. Загрузчик Python проверяет каждую часть и собранный оригинал. Прерванную загрузку можно повторить той же командой. По умолчанию файлы сохраняются в `downloads/`; путь можно задать через `--dest`. [Каталог файлов](release-assets.json) · [страница выпусков](https://github.com/rryltsev/Ti-Al-project/releases).

| Группа для `--group` | Содержание | Архивов | Размер до распаковки |
|---|---|---:|---:|
| `article` | Наборы DFT и история обучения трёх моделей статьи | 6 | 278 МиБ |
| `dpa4-restart` | Финальные состояния обучения DPA4 для N200 и N694 | 4 | 160 МиБ |
| `grace-base` | Общий базовый checkpoint для 22 обученных моделей GRACE | 1 | 161 МиБ |
| `phase` | Фононные силы, окна Монте-Карло, траектории и свободные энергии | 25 | 736 МиБ |
| `validation` | Численные данные проверок моделей и расплава, исторические CPU-экспорты | 2 | 1,41 ГиБ |
| `legacy` | Исходные структуры MACE, серии DFT и MD, структурные и термодинамические данные | 6 | 2,08 ГиБ |

```sh
python tools/release_assets.py --list
python tools/release_assets.py --list --group phase
python tools/release_assets.py --get --name "article-dataset-PBE.zip"
python tools/release_assets.py --verify --name "article-dataset-PBE.zip"
```

Чтобы увидеть исходные пути внутри загруженного ZIP, выполните `python -m zipfile -l downloads/article-dataset-PBE.zip`. Переносимые команды распаковки других архивов приведены в руководствах по сериям. Там указаны каталог назначения и дополнительные зависимости. Новые расчёты на UMT требуют личного SSH-доступа и выбора учётной записи для серии.

## Границы снимка

Сохраняются первичные метки, модели, код анализа, исходники отчётов и версии результатов, нужные для сравнения. Из старых сред используются сведения о версиях и настройках. Полные PAW-наборы для новых VASP-расчётов берутся из лицензированной установки. Внешние данные MTP Qi, ATAT и CALPHAD Liang идентифицируются по источнику и контрольной сумме в [руководстве по фазовому расчёту](phase-reproduction.md).

Машинный манифест прежнего резервирования содержит пути и SHA-256 для 40 промежуточных архивов обучения общей величиной 6 218 149 936 байт. Их исходная копия сохраняется на рабочей станции в `research/tial_fm/runs/*/storage-recovery/`. Доступность любых дополнительных копий на GitHub определяется каталогом вложений. Конечные веса и таблицы сравнений имеют отдельные точки входа выше. [Реестр промежуточных состояний](research-recovery.csv)

GitHub блокирует отдельные обычные Git-файлы свыше 100 МиБ и push свыше 2 ГиБ. Файлы выпусков можно скачивать отдельно. При обновлении проекта добавляйте большие численные результаты отдельными вложениями и записывайте их размер и SHA-256 вместе с кодом, которым они получены. [Лимиты GitHub](https://docs.github.com/en/repositories/creating-and-managing-repositories/repository-limits) · [лимиты выпусков](https://docs.github.com/en/repositories/releasing-projects-on-github/about-releases).
