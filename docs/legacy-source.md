# Первичные материалы TiAl-Project

Каталог `legacy/` воспроизводит структуру исходной папки `TiAl-Project` с рабочего стола. Здесь собраны ранние версии кода, подготовка геометрий, настройки VASP и данные для исследования свойств. Финальные научные выводы и позднейшие исправления приведены отдельно в [руководстве по валидации](validation.md). Для исторического рисунка или таблицы сначала сверьте функционал, номер чекпойнта, состав и температуру с отчётом соответствующего расчёта.

## Как найти нужный файл

Код, манифесты, компактные таблицы, итоговые изображения и файл с исходным замыслом статьи читаются сразу после клонирования. Для каждого крупного файла в [каталоге архивов](../legacy/archive-index.csv) указаны имя вложения выпуска, путь распаковки, размер в байтах и SHA-256. Можно скачать одно вложение и распаковать нужную подпапку в корень клона. Внутри каждого ZIP также лежит `legacy-archive-index.json` с контрольными суммами.

## Происхождение выборки

База MACE использовалась как источник геометрий. Для старта с готовой выборки найдите в архиве `legacy/MACE-dataset-gen/MACE-database/TiAl-liq-relax-ss_select-1000.xyz`. Проверку состава, дескрипторов и качества можно проследить по коду и CSV в соседней папке. Отдельная папка `MD-Solid-Solutions/Ti-Al_SS/RESULT` хранит историю исходных твёрдых траекторий и варианты выборки. Обучающие и тестовые данные следует идентифицировать по соответствующим замороженным разбиениям и хешам. Метки MACE и DFT имеют разное происхождение. [Код отбора и QC](../legacy/MACE-dataset-gen/MACE-database/) · [Сопоставление с Test50](../testset/TiAl-test50-v1/README.txt)

В `RESULTS/{Al,Ti,TiAl}` исходного DFT-каталога найдено по 1000 наборов входов для PBEsol и r2SCAN. Закрывающий тег XML есть у 998 и 993 записей соответственно. У PBEsol открыты или отсутствуют XML для TiAl/458 и TiAl/697. У r2SCAN это Ti/39 и TiAl/0, 164, 233, 458, 998, 999. Закрывающий тег характеризует целостность записи. Для использования метки следует также проверить электронную сходимость и согласованность ячейки, атомов и сил с исходной геометрией. Отобранные XML сохранены как получены, в том числе неполные. Для PBE исходный Desktop-каталог `VASP-output` серии XML не содержал.

## Восстановление вычислительного окружения

Во многих исторических скриптах зашиты пути к домашним папкам, названия Slurm-разделов и старые варианты загрузки моделей. Для воспроизведения сначала задайте в своей рабочей копии пути к восстановленным данным и нужной модели. Для новых DPA4-расчётов требуется проверенный экспорт Triton2 с сопоставлением энергии, сил и напряжений. Для VASP выберите доступную лицензированную установку и соберите POTCAR нужных типов и версий по метаданным. Учётную запись UMT согласуйте до отправки новой серии.

Большое параллельное представление MACE в `mace_to_deepmd_TiAl-SS` занимало около 6,6 ГиБ в форматах raw и NPY. В архив вошли исходные XYZ, файлы выбора и сценарии конвертации. Переэкспорт в DeepMD следует проверять по составам и числу кадров. Сохранённые XML позволяют заново извлекать величины для постобработки. Для продолжения с промежуточного электронного состояния исходные WAVECAR/CHGCAR нужно восстанавливать отдельно.

Для переносимой распаковки ZIP, в том числе записей со сжатием LZMA, используйте стандартную библиотеку Python. Например, из корня клона команда `python -m zipfile -e downloads/tial-legacy-dft-inputs-and-outputs.zip .` восстанавливает дерево `legacy/` с исходными именами и каталогами.
