
1. Статья посвящена сравнению MLIP для системы Ti-Al, построенных на основе DFT на различных обменно корреляцмонных функционалах (PBE, PBE-sol, r2SCAN).

2. Основной результаты статьи - r2SCAN дает лучшую точность для наблюдаемых свойств для составов, богатых титаном. 

3. MLIPs строились в рамках идеологии трансферного обучения по следующему алгоритму:
 - с помощью MACE-MPA-0 был построен синтетический датасет.
Конфигурации датасета состояли из МД траекторий для SQS структур твердых растворов, МД траекторий расплава и релаксаций из точек таких траекторий, взятых через каждую пс (1000 шагов).
Из большого ситтетического датасета были отобраны 1000 репрезентативных конфигураций с помощью библиотеки ASAP.
 - Для отобранных конфигураций были произведены SPE расчеты с помощью VASP c использование трех обменно корреляцмонных функционалах: PBE, PBE-sol, r2SCAN.
 - Полученные DFT датасеты были использованы для finetune потенциала DPA4-neo
 
 4. Полученные потенциалы использовались для расчета следующих свойств:
 - температуных зависимостей плотности чистого титана включая альфа, бета и жидкую фазы
 - фононы для alpha-Ti, и Ti3Al
 - энтальпии смешения расплавов
 - температура плавления чтистго титана
 - динамическая вязкость расплавов
 
Описание директории с исходными данными
 
MACE-dataset-gen: скрипты использованные для генерации искуственного датасета и сам датасет

MD-scripts: скрипты для МД расчетов свойств

VASP-input: управляющие файлы VASP

MD-results: результаты МД расчетов. В данной директории есть несколько поддиректорий
- density_DPA4-neo: резульатты расчета плотности (три файла для разных функционалов)
- mixing_enthaphy: резульатты расчета энтальпий смешения (три файла для разных функционалов)
- phonons_DPA4-neo: фононные расчеты. Здесь кроме рачетов с пмошью finetuned DPA4 есть расчеты для pretrained DPA4 для alpha-Ti
- viscosity_scan. Это результаты расчета вязкости. Данных еще мало, это свойство в процессе расчета.
Также в данной папке есть файл Tm_DPA4.docx со сравнительной таблицей расчетов температуры плавления
