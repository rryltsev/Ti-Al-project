TiAl-test50-v1 — общий набор геометрий для PBE / PBEsol / r2SCAN
Дата фиксации: 21 октября 2026, Asia/Yekaterinburg.
Статус: 50 геометрий подготовлены; новых DFT-меток нет; расчёты не запускались.

СОСТАВ
25 конфигураций из жидкого ASAP-архива, по 216 атомов; x(Al) = 0–1.
8 конфигураций из hcp-траекторий, по 256 атомов; x(Al) = 0–0.390625.
9 конфигураций из bcc-траекторий, по 250 атомов; x(Al) = 0–0.6.
8 конфигураций из gamma-L10-траекторий, по 250 атомов; x(Al) = 0.352–0.648.
Всего 11 698 атомов. В твёрдой части — 25 разных исходных траекторий.
Названия семейств обозначают происхождение, а не доказанную текущую фазу.

Исходный каталог D019 содержит 11 неудачных запусков: NPT остановился до MD,
поскольку требовалась верхнетреугольная матрица ячейки. В этих каталогах нет
xyz-траекторий. D019 в тест не входит; его исходные POSCAR не подменяют MD.
Список подтверждающих логов находится в validation.json.

ПРОВЕРКА ПЕРЕСЕЧЕНИЙ
Проверены исходный ASAP-отбор TiAl-liq-relax-ss_select-1000.xyz, все три
финальных XYZ в DPA4-finetune, все coord.npy в DPA4-finetune и VASP-output
со всеми доступными разбиениями, а также все POSCAR* в VASP-output.
11 978 записей свелись к 1000 уникальным геометриям исходного отбора.
Ни одна из 200 структур жидкого архива с ними не совпадает.
В TiAl-SS-mace_select-200.xyz совпадают 34 из 200 кадров.
В окончательном Test50: 0 совпадений с объединением старых наборов,
0 внутренних дубликатов. Источники и SHA256 перечислены в source_audit.json,
reference_auxiliary_sha256.json и reference_origins.json.
Идентификаторы reference_id — нумерация с нуля исходного отбора 1000.

Сравнение учитывает химические типы, периодические образы, перестановку
атомов и общий перенос; допуск для ячейки/координат 5e-5 Å. Ориентация и
базис ячейки считаются сохранёнными в исходной цепочке экспорта. Полный
поиск произвольных эквивалентных кристаллографических базисов не выполнялся.
Дополнительно для выбранных структур выполнен поиск близких конфигураций
того же размера и состава: периодическое назначение атомов одного элемента,
снятие однородной деформации ячейки, локальная поправка общего переноса.
Отбрасывание: RMSD < 0.1 Å и изменение матрицы ячейки < 1% одновременно.
Минимальный найденный RMSD до старого набора — 0.2350 Å.
Этот дополнительный критерий — диагностический, не универсальный matcher.

ОТБОР
Полностью просмотрены 46 траекторий по 1000 кадров (46 000 кадров).
Найдены источники 120 геометрий старого отбора. Исключён первый 1 пс;
кандидаты брались с шагом 25 сохранённых кадров = 0.25 пс.
Временное окно исключения относительно старого отбора — ±0.5 пс.
У выбранных структур фактический минимальный отступ — 0.85 пс.
Точное соответствие кадр/шаг/время проверено по stat.csv, энергии и
кинетической температуре. XYZ начинается с шага 10, нумерация кадров с нуля.
После фильтров осталось 1507 твёрдых кандидатов + 200 жидких = 1707.
Контроль геометрии: конечные координаты, положительный объём, минимальное
межатомное расстояние >= 1.8 Å. В Test50 минимум составляет 1.8621 Å.

Дескриптор: DScribe SOAP, periodic=True, species=[Al,Ti], r_cut=5 Å,
n_max=4, l_max=3, sigma=0.5 Å, average=outer, нормировка вектора на единицу.
В каждом семействе диапазон состава разбит на 5 равных интервалов;
приоритет — менее заполненным интервалам. Первый кадр ближайший к среднему
SOAP-вектору семейства; затем farthest-point selection по расстоянию до
уже выбранных кадров семейства. Для твёрдых — один кадр на траекторию.
Детерминированный порядок источников; энергии/силы/ошибки MLIP не использованы.
Параметры: selection_protocol.json. Дескрипторы и выбранные индексы:
selection_descriptors.npz; соответствие индексов: candidate_manifest.json.
Официальная документация метода:
https://singroup.github.io/dscribe/latest/tutorials/descriptors/soap.html
https://docs.ase-lib.org/ase/neighborlist.html

ГРАНИЦЫ НЕЗАВИСИМОСТИ
Это зафиксированный holdout без пересечения с предоставленными наборами
дообучения/валидации. Большинство твёрдых кадров происходят из траекторий,
представленных в старом наборе: временной зазор 0.5 пс — эвристика, не
измеренное время декорреляции. Нельзя называть это полностью независимым
набором траекторий. Пересечение с pretraining foundation-моделей неизвестно.
Для жидкого архива исходные времена и полные траектории недоступны;
независимость на уровне траекторий проверить нельзя. Кинетические температуры
выбранных кадров — 590–3062 K, поэтому название liquid следует понимать как
метку исходного пула. У твёрдой части температуры 898–1080 K.
Это сбалансированный набор для проверки на разнообразных конфигурациях,
а не случайная выборка термодинамического ансамбля. 50 структур ограничивают
точность оценок по узким подгруппам. Полное устранение корреляции потребует
новых MD-траекторий с независимыми начальными условиями.

ФАЙЛЫ И СЛЕДУЮЩИЙ ЭТАП
POSCARS/POSCAR.TiAl-test-001 ... POSCAR.TiAl-test-050 — входные геометрии.
test50.extxyz — те же 50 конфигураций без калькуляторов, энергий, сил,
напряжений и скоростей MACE. Порядок атомов в POSCAR отсортирован по элементу;
нельзя сопоставлять массивы сил из разных форматов только по индексу атома.
manifest.json / manifest.csv — состав, происхождение, шаг, температура,
объём, дистанции, идентификаторы и SHA256 каждого POSCAR.
validation.json — проверка исходников, форматов, пересечений и инвариантности.
coverage.png / coverage.pdf — охват состава/объёма и SOAP-дистанции.
SHA256SUMS.json — контрольные суммы всего пакета, кроме самого этого файла.

Для разметки использовать одни и те же POSCAR с теми же structure_id во всех
трёх функционалах: 50 × 3 = 150 статических single-point расчётов, без
релаксации геометрии. Перед запуском отдельно согласовать и проверить
численную сходимость протокола DFT, PAW, k-сетки, smearing и SCF-критерии.
Если расчёт не сошёлся, сохранять этот ID, разбирать причину; не заменять
структуру на более удобную после просмотра ошибок модели.
Набор не использовать для дообучения, подбора гиперпараметров или выбора
чекпойнта. Зафиксировать хеши моделей до просмотра новых DFT-меток.

После разметки: parity plots и MAE/RMSE для E/N (meV/atom), компонентов сил
(eV/Å), при необходимости напряжений (GPa с общей конвенцией знака).
Показывать общие метрики и отдельно жидкую/твёрдую части, силы Al/Ti.
Сравнивать каждый потенциал с соответствующим XC на одинаковых structure_id.
Сдвиги энергий, если нужны, определять по обучающим данным или физически
заданным референсам; не подгонять по Test50. Для интервалов неопределённости
ресемплировать целые структуры/известные группы, не отдельные компоненты сил.
При сравнении MLIP и DFT использовать тот же POSCAR-порядок атомов.

ВОСПРОИЗВЕДЕНИЕ
Скрипты в reproduce/. Для нового прогона скопировать их в отдельный пустой
рабочий каталог, установить requirements-lock.txt в Python 3.11.5 и задать
переменную TIAL_SOURCE_ROOT на корень исходного TiAl-Project.
Порядок: audit_sources.py → select_testset.py → verify_testset.py →
finalize_testset.py. Опция audit_sources.py --scan-only явно использует уже
созданный локальный кэш reference.pkl; применять только к тем же исходникам.
Не перезаписывать этот замороженный набор: новый протокол = новая версия.
Первичный аудит выполнен в другом доступном окружении, см. audit-environment.txt.
Ключи SSH, POTCAR и модели в пакет не входят.
