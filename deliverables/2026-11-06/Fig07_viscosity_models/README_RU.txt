Сравнение моделей вязкости жидкого Ti-Al при 1873 K
Дата: 6 ноября 2026 г.

Результат
Выбраны три литературные модели для металлических расплавов:
Moelwyn-Hughes, Schick-Brillo-Egry-Hallstedt (2012) и Kaptay (2003).
Козлов-Романов-Петров (KRP) оставлен для сравнения. На одних и тех же
входных данных Schick лучше остальных описывает эксперимент и обе
MD-зависимости. Это результат для данных Ti-Al и выбранных входных
параметров, а не универсальное ранжирование моделей.

На каждом графике показаны три варианта энтальпии: эксперимент, PBE,
r2SCAN. Подгонки к вязкости сплавов нет. Текущие файлы статьи сохранены;
figure7_schick_candidate.pdf представляет отдельный вариант рис. 7.

Формулы
x = x_Al; 1-x = x_Ti; H = интегральная энтальпия смешения, Дж/моль атомов.
R = 8.31446261815324 Дж/(моль K), T = 1873 K.
G = eta_Ti^(1-x) eta_Al^x; A = (1-x)eta_Ti + x eta_Al.

1. Moelwyn-Hughes: eta = A [1 - 2H/(RT)].
   Использована именно форма с интегральной H из Schick2012, уравнение (1).
   Модель связывает отклонение от арифметического смешения вязкостей
   с энтальпией. Это распространённый ориентир для металлических сплавов.

2. Schick-Brillo-Egry-Hallstedt:
   eta = G exp[(1-x)ln(1-x) + x ln(x) - H/(RT)].
   Выражение следует из уравнений (8), (11), (12) Schick2012.
   Модель разработана для Al-Cu с сильным неидеальным смешением.
   Слагаемые x ln(x) сохранены; 0 ln(0) = 0. При x=0.5 их суммарный
   множитель равен 0.5. Пропуск этого множителя изменил бы результат вдвое.

3. Kaptay (2003):
   eta = G [V_Ti^(1-x) V_Al^x / Vm] exp[-alpha H/(RT)], alpha = 0.155.
   Это преобразование уравнения Эйринга с активационными энергиями
   чистых компонентов. Требуются также молярные объёмы. Использован
   опубликованный коэффициент; alpha не подбирался для Ti-Al.
   Это модель Kaptay 2003, а не более поздняя модель Budai-Benkö-Kaptay.

4. KRP (прежний расчёт): eta = G exp[-H/(3RT)].

Предупреждение о соглашениях Moelwyn-Hughes
В литературе встречаются другие записи под тем же названием. В частности,
Mohr2020, уравнение (17), использует A[1-2x(1-x)-Omega/(RT)], где Omega
названа параметром энтальпии смешения. Она здесь не отождествляется с
интегральной H. Наш расчёт не является воспроизведением уравнения (17)
Mohr2020 или соответствующего расчёта Takeda2025. Выбранная форма
A[1-2H/(RT)] явно приведена в Schick2012 и Dobosz2021, уравнение (6).

Чистые компоненты
Ti: eta = 0.61 exp[27000/(8.31 T)] = 3.4570167733 мПа с при 1873 K.
Источник: та же предварительная транскрипция Ishikawa2012, что в рис. 7b.
1873 K ниже температуры плавления Ti; это продолжение для жидкого состояния.
Al: eta = 10^(-0.7324+803.49/T) = 0.4972623575 мПа с.
Источник: рекомендованная корреляция Assael2006, уравнение (19), основанная
на критическом анализе экспериментальных данных. Это не простое среднее.
Её подтверждённый диапазон 933-1270 K; здесь используется экстраполяция.
Заявленные 14% неопределённости внутри диапазона не переносятся на 1873 K.

Энтальпия
Полностью повторяет предыдущий расчёт KRP:
- Эксперимент: предварительная оцифровка калориметрических данных при
  2000 K, воспроизведённых на рис. 7 Witusiewicz2008. Принято H(1873 K)
  приблизительно равной H(2000 K). Погрешность чтения около 0.2 кДж/моль
  не является экспериментальной неопределённостью.
- PBE и r2SCAN: архивные MD-энтальпии при 1873 K, полная энергия плюс
  внешнее давление pV, относительно чистых жидких компонентов при той
  же температуре и для той же модели.
- PBE здесь соответствует исходной модели с checkpoint 5000 из рис. 7a,
  а не checkpoint 15000 при 2000 K, используемому на рис. 6.
Между узлами линейно интерполируется H; затем вычисляется вязкость.
Изломы кривых отражают это правило интерполяции. Положение рассчитанного
максимума с шагом 0.001 по x не означает такую точность исходных данных.

Молярный объём для Kaptay
Во всех трёх вариантах H используется один экспериментальный объём,
чтобы сравнение отражало замену только энтальпии.
Brillo2025, табл. 7: V_Ti = 11.45; V_Al = 12.94555 см3/моль.
Уравнение (7), A=Al, B=Ti:
Vm = (1-x)V_Ti + x V_Al + x(1-x)[-2.66 - 2.831(2x-1)] см3/моль.
Коэффициенты взяты из столбца при 1873 K табл. 8. Отдельный столбец
температурных аппроксимаций этой таблицы не точно воспроизводит указанные
изотермические коэффициенты и в этом расчёте не используется.
Если пренебречь избыточным объёмом, вязкость Kaptay меняется максимум
на 6.43%. Изменение alpha от 0.155 до 0.140/0.170 меняет её не более
чем примерно на 3.3%. Это не устраняет полученное занижение вязкости.
Эти оценки чувствительности не являются полными доверительными интервалами.

Сравнение с экспериментальной вязкостью
Использованы пять корреляций Takeda2025, табл. 3, при x_Al = 0.45, 0.60,
0.70, 0.80, 0.90. Вязкости при 1873 K: 5.304558, 3.554014, 2.678678,
1.763948, 1.436930 мПа с соответственно. Для x_Al=0.45 и 0.60 это
экстраполяция на 3 K выше опубликованного диапазона.
MAPE = 100 mean(|eta_model - eta_Takeda|/eta_Takeda), все пять точек
имеют одинаковый вес. Это описательная метрика, не проверка значимости.

Модель               H эксперимент    H PBE       H r2SCAN
KRP                    43.2%          46.2%         40.4%
Moelwyn-Hughes        100.4%          83.7%        114.0%
Schick                 13.5%          24.4%         18.7%
Kaptay                 54.0%          55.1%         53.0%

RMSE с экспериментальной H, мПа с:
KRP 1.5224; Moelwyn-Hughes 3.3784; Schick 0.5238; Kaptay 1.9108.
При x_Al=0.45 Schick даёт 4.2783 (H_exp), 3.9432 (H_PBE),
5.4847 (H_r2SCAN) мПа с, экспериментальная корреляция - 5.3046 мПа с.
Для H_exp и H_r2SCAN максимум Schick получается около x_Al=0.5,
для H_PBE - около 0.4. Экспериментальная вязкость доступна только
при x_Al=0.45-0.90; Ti-богатая ветвь максимума ею не проверяется.

Сравнение с соответствующей MD-вязкостью
При H_PBE сравниваем с MD PBE; при H_r2SCAN - с MD r2SCAN, по 11 точкам
рис. 7a. Чистые вязкости в формулах всё равно экспериментальные.
MAPE для Schick: 15.5% (PBE) и 21.0% (r2SCAN), для KRP: 33.8% и 45.9%.
Таким образом, Schick лучше передаёт и наблюдаемую в MD немонотонность,
хотя заметное занижение r2SCAN-вязкости в средней области сохраняется.

Проверки
Проверены размерности и оба чистых предела всех моделей; прежние кривые
KRP воспроизводятся с относительным допуском 1e-13. Формулы Schick
дополнительно сверены с исходной аррениусовской записью, Kaptay -
с исходным уравнением Эйринга в единицах СИ. Контрольные суммы подтверждают,
что канонические файлы рисунка, методов, результатов и входов не изменены.
Оба PDF отрисованы через pdftoppm и визуально проверены.
