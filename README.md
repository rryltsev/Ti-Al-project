# Ti–Al

Рабочий архив расчётов бинарной системы Ti–Al. Он объединяет исследование межатомных потенциалов DPA4 и GRACE, проверку по DFT и фононам, расчёты свойств расплава, рукопись с дополнительными материалами и воспроизведение равновесия α/α₂.

## Работа на другом компьютере

```sh
git clone https://github.com/rryltsev/Ti-Al-project.git
cd Ti-Al-project
```

Откройте папку клона в Codex. Правила выбора учётной записи UMT и проверки экспорта DPA4 хранятся в [AGENTS.md](AGENTS.md). Когда возвращаетесь к работе со второго компьютера, выполните `git pull --ff-only`. Результаты завершённой работы перед переключением сохраните коммитом и отправьте командой `git push`.
