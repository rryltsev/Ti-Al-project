# Ti–Al

Материалы проекта по межатомным потенциалам, свойствам бинарного сплава и равновесию α/α₂.

| Направление | Результат и источник |
|---|---|
| Проверка моделей на DFT | На 49 общих структурах Test50 значения RMSE энергии для PBE, PBEsol и r²SCAN составили 1,467, 1,766 и 1,578 мэВ/атом. PBE 20k выбран после просмотра набора. [Метрики](manuscript/supporting_data/test49_metrics.json) |
| Дообучение GRACE | При трёх seed увеличение N200 до N694 улучшило ошибки сил, напряжений и фононных ветвей TiAl, но увеличило расхождение DOS Ti₃Al. [Сводная таблица](research/tial_fm/reports/30_grace_pbe_n694_results.md) |
| Кластерное разложение | На авторской матрице и исходных метках независимый код воспроизвёл 46 × 20 корреляций и ECI на девяти объёмах. [Сопоставление с авторским расчётом](phase_reproduction/author_comparison/README.md) |
| Прямой MTP, вершина сольвуса | Для 2304 атомов критерий равных весов при Q=0,42 даёт 1262,59 K при W<0,35 и 1243,46 K при W<0,40. Разность 19,13 K относится к этим двум ограничениям. [Результаты](phase_reproduction/solvus_cage2304/analysis/direct/direct_temperature_zeros.json) |
