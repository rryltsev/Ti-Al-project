# Ti–Al

Рабочий архив расчётов бинарной системы Ti–Al. Он объединяет исследование межатомных потенциалов DPA4 и GRACE, проверку по DFT и фононам, расчёты свойств расплава, рукопись с дополнительными материалами и воспроизведение равновесия α/α₂.

## Работа на другом компьютере

```sh
git clone https://github.com/rryltsev/Ti-Al-project.git
cd Ti-Al-project
```

Откройте папку клона в Codex. Правила выбора учётной записи UMT и проверки экспорта DPA4 хранятся в [AGENTS.md](AGENTS.md). Когда возвращаетесь к работе со второго компьютера, выполните `git pull --ff-only`. Результаты завершённой работы перед переключением сохраните коммитом и отправьте командой `git push`.

## Проверка нового клона

Эти команды выполняются из корня проекта с Python 3.10 или новее. Первая сверяет сохранённые данные Test50 и воспроизводит 24 метрики. Вторая показывает доступные наборы для восстановления с исходными путями расчётов.

```sh
python testset/verify_archived_metrics.py
python tools/restore_research.py --list
```

Для подготовки статей понадобятся LaTeX и пакеты из преамбулы. Для повторного научного расчёта версии Python, NumPy, ASE, DeePMD, TensorPotential, LAMMPS и VASP выбирайте по манифестам конкретной серии. Ссылки на старые рабочие каталоги в неизменённых журналах служат для сопоставления происхождения. Для переносимых команд используйте руководства в таблице. Если Windows ограничивает длину путей, используйте короткий каталог клона, например `C:/work/TiAl`, либо выполните `git clone -c core.longpaths=true https://github.com/rryltsev/Ti-Al-project.git`.
