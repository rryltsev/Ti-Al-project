# Одно окно VCSGC

Исполняемая программа принимает геометрические орбиты и коэффициенты для одной температуры. Для статической и гармонической моделей достаточно одной строки коэффициентов при опорном объёме. Для QHA требуется таблица по объёмам с одинаковым порядком орбит. Энергия кластера задаётся в эВ, температура в K, объём в Å³/атом, концентрация — в атомных долях.

Из каталога `phase_reproduction` в окружении с Python 3 и NumPy:

```bash
c++ -O3 -std=c++11 mc/vcs.cpp -o vcs
python mc/check_sampler.py ./vcs
python mc/prepare.py reference_static
./vcs reference_static/motifs.txt reference_static/coefficients.txt \
    8 8 6 1000 0.16 100 3.09 10000 40000 10 1729 random static_S1 0 window.csv
```

После двух имён файлов задаются nx, ny, nz; температура; центр окна c₀; κ; обменный потенциал Δμ₀; число проходов уравновешивания и производства; интервал сохранения; seed; начальное состояние `random` или `ordered`; имя модели; полуразмах симметричного предложения по объёму; файл результатов. Ячейка 8×8×6 содержит 768 узлов, один проход состоит из 768 случайных попыток замены. Для условного старта `ordered` вначале заполняется одна предпочтительная подрешётка. На каждом сохранённом кадре параметр дальнего порядка вычисляется по наиболее заполненной из четырёх подрешёток.

Для собственных взаимодействий ATAT укажите NPZ, полученный из энергий MTP и фононов. Файл `grid.npz` содержит J_static, J_vib, имена орбит и сетки температуры и объёма. Здесь `path/to/grid.npz` означает конкретный результат подгонки, а `input_qha_1000` — новый выходной каталог.

```bash
python mc/prepare.py input_qha_1000 --grid path/to/grid.npz --model QHA --temperature 1000
./vcs input_qha_1000/motifs.txt input_qha_1000/coefficients.txt \
    8 8 6 1000 0.16 100 3.09 10000 40000 10 1729 random atat_QHA 0.045 window_qha.csv
```

В объёмной модели предложения симметричны по v при P = 0. Мера равна dv, выход за диапазон узлов отклоняется, коэффициенты внутри диапазона интерполируются натуральным кубическим сплайном. Эти детали и seed задают реализацию независимого расчёта. Код сравнивает инкрементальные энергии с полным пересчётом по орбитам и останавливает ошибочный прогон. Для численной проверки меры `check_sampler.py` сравнивает распределения состава и объёма с точным результатом для конечной решётки.

`atat_windows.py` готовит серию окон сразу для заданных температур и модели. Для каждого среза сохраняются коэффициенты, параметры, seed и хеш исходного NPZ. Скрипт `umt_run.py` обслуживает именованные серии проекта на UMT. Каталог `runs/<имя>` хранит протокол подачи, таблицу окон, логи проверки и `samples.csv.gz`. Результаты окон обрабатываются программой [vcsgc.py](../thermo/vcsgc.py).

## Проверочные изотермы S3

Опция `atat_windows.py GRID НОВЫЙ_КАТАЛОГ --s3` восстанавливает протокол массива `atat_s3_5120` из собственных коэффициентов. Он включает статику при 1600, 1625 и 1650 K, HA и QHA при 1200 и 1225 K. Для каждой из семи изотерм использованы 69 центров от 0.02 до 0.36 с интервалом 0.005. В S3 интервал 0.005 указан для статики при 1600 и 1650 K. Для других изотерм перенос этого шага и диапазон из основной сетки являются решениями этой репродукции. Для каждой пары изотермы и центра используется независимый случайный старт, 5120 узлов, κ=100 эВ, 10 000 проходов уравновешивания и 40 000 производственных проходов с записью каждого десятого.

Программа `collect_s3.py` загружает законченные изотермы, проверяет окна и собирает итоговые траектории в `runs/atat_s3_5120/samples.csv.gz`. Сверенные исходные данные отдельной изотермы доступны в `sections/<модель>_<температура>/` внутри каталога запуска. Номер массива UMT — 21021275.

На основной серии оценены интегральные времена корреляции состава и порядка. Для четырёх окон в исследуемой области τ порядка превысило 200 сохранённых отсчётов — длину исходного блока bootstrap. Это статика при 1600 K и c₀=0.250, 1625 K и c₀=0.260, 1650 K и c₀=0.280, а также QHA при 1200 K и c₀=0.250. Исходные значения τ, SHA-256 диагностических таблиц и независимые seed для каждой пары записаны в `inputs/atat_s3_repeats/fit_source.json` и `windows.tsv`.

`prepare_s3_repeats.py` формирует по два запуска для выбранного окна, со случайным и D0₁₉-подобным стартом. Каждая из восьми траекторий содержит 50 000 проходов уравновешивания и 400 000 производственных проходов с записью каждого десятого. Номер массива UMT — 21021794. Команда `python mc/collect_s3.py atat_s3_repeats` сохраняет результаты по парам. Для оценки стационарности длинной траектории 40 000 сохранённых отсчётов делят на 20 последовательных блоков по 2000. Сопоставляют длину блока с измеренным временем корреляции, затем сравнивают средние между половинами и между двумя стартами.
