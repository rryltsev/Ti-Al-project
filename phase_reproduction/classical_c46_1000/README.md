# Классический C46 при 1000 К

Классический и квантовый варианты используют одни и те же 46 декораций C46 v16, разбиение на обучение и контроль, маски фононной устойчивости, 20 орбит и статические энергии MTP Qi. В QHA допускаются изменения объёма при \(p=0\) и фиксированном отношении осей \(c/a=4{,}6046/2{,}9446\). Концентрации в таблицах контактов даны в атомных процентах Al, изменения концентраций — в процентных пунктах.

## Две границы при 1000 К

| \(N=5120\), модель QHA–MC | α, ат.% Al | α₂, ат.% Al |
|---|---:|---:|
| Авторский C46, квантовый, сохранённые 13 окон | 14,958 | 21,958 |
| Повторный квантовый C46, 13 окон | 14,943 | 21,931 |
| Классический C46, 13 окон | 14,896 | 21,922 |
| Повторный квантовый C46, 25 окон | 14,933 | 21,922 |
| Классический C46, 25 окон | **14,896** | **21,921** |

На 25 окнах парная разность «классика минус квантовая статистика» равна −0,0370 п.п. для α (условный 95%-й интервал от −0,0477 до −0,0266) и −0,0011 п.п. для α₂ (от −0,0146 до +0,0116). При переходе с 13 на 25 окон оба классических состава изменились меньше чем на 0,002 п.п. Отдельные начальные траектории на исходной сетке давали для правого классического состава 21,840 и 22,020 ат.% Al. Этот разброс показывает чувствительность абсолютной правой границы к выборке.

Для сравнения двух серий на исходных 13 центрах разброс классической границы α₂ равен 0,180 п.п. с собственным условным 95%-м интервалом [0,049; 0,294]. Интервалы разности парных квантово-классических поправок двух серий включают нуль для обеих фаз. Отдельная третья серия только на 12 промежуточных центрах дала 14,928 и 21,891 ат.% Al в классическом ансамбле. [Проверка чувствительности к серии](mc_start_sensitivity.json).

Прямой классический MTP в том же механическом ансамбле при \(N=1400,\ W<0{,}40\) даёт 16,083 и 22,159 ат.% Al. Его расхождение с классическим C46 на плотной сетке составляет +1,187 и +0,238 п.п. соответственно. Общая классическая статистика ядер сохраняет расхождение в α. В него входят различия кластерной аппроксимации и квазигармоники с атомистическим расчётом в ограниченном кристаллическом бассейне, а также конечного размера и оценивания границ.

## От исходных энергий к коэффициентам

Из каталога проекта при наличии NumPy и SciPy команды ниже восстанавливают метки, коэффициенты и результаты среднего поля. В первой команде вместо `AUTHOR_PACKAGE` указывается каталог авторского комплекта, содержащий `structures/index.csv` и `models/HA_QHA/volume_temperature_coefficients.npz`.

```powershell
python phase_reproduction/classical_c46_1000/fit_classical.py AUTHOR_PACKAGE
python phase_reproduction/classical_c46_1000/spectra_validation.py
$d = 'phase_reproduction/classical_c46_1000'
python phase_reproduction/thermo/mfa.py "$d/classical_grid.npz" "$d/mfa_classical" --temperatures 1000 --models HA QHA --volume-spline not-a-knot
python phase_reproduction/thermo/mfa.py "$d/quantum_grid.npz" "$d/mfa_quantum" --temperatures 1000 --models HA QHA --volume-spline not-a-knot
```

[Колебательные метки для 409 устойчивых сочетаний структуры и объёма](structure_labels.csv) и [изменения всех ECI](eci_changes.csv) дают возможность проследить результат до исходной декорации. [Проверка подгонки](fit_diagnostics.json) содержит контрольные суммы входных архивов и зависимость классических меток от температурного диапазона. [Проверка по спектрам](spectra_validation.json) отдельно сопоставляет методы на одних частотах и результаты двух независимых фононных расчётов на совпадающих декорациях. Для её повторения нужны архивы ATAT и малых ячеек, указанные в файле проверки.

## Монте-Карло

`prepare_mc.py` готовит коэффициенты и вторые производные по объёму для авторского сплайна `not-a-knot`, орбиты ГПУ и 13 окон с ограниченной дисперсией состава. В каждом каталоге запуска есть `manifest.json` с размером, затравкой, начальным состоянием и длиной траекторий, `windows.tsv` с параметрами отдельных окон, исходник драйвера и каталог `samples/`. В сжатых CSV записаны объём, состав, химический порядок, энергия и суммы по каждой парной и тройной орбите. Для воспроизведения серии в новом каталоге передайте параметры из соответствующего манифеста в `prepare_mc.py`, скомпилируйте `vcs.cpp` и запустите `run_local.py` с путями к каталогу и исполняемому файлу.

На основной ячейке запущены классическая и квантовая серии на 13 авторских центрах от 0,13 до 0,25 по атомной доле с шагом 0,01. Ещё 12 промежуточных окон с шагом 0,01 начиная с 0,135 созданы с флагом `--midpoints`. Это увеличивает разрешение итоговой сетки вдвое. На каждом размере файлы траекторий для двух гамильтонианов независимы. При нахождении разности между квантовой и классической бинодалями обе статистики вычислялись на одних и тех же ресэмплированных блоках.

Пересчёт результатов из уже полученных траекторий выполняется из этого каталога. Для статистического сравнения с прямым MTP используется его серия \(N=1400\), \(W<0{,}40\) при фиксированном отношении осей.

```powershell
python paired_mc.py mc5120q_b mc5120c_a --out paired5120.json --bootstrap 768 --seed 674251
python paired_mc.py mc5120q_b mc5120c_a --out paired5120_longblocks.json --bootstrap 512 --block-multiplier 12 --seed 674252
python paired_mc.py mc768q_a mc768c_b --out paired768_final.json --bootstrap 512 --seed 681025
python dense_grid.py --bootstrap 512
python interpolation_check.py
python compare_direct.py paired5120.json --dense dense_grid.json
```
