# Восстановление бинодали α/α₂ в Ti–Al

Основной независимый расчёт использует собственные энергии MTP для структур, построенных ATAT. В `results/atat/` собраны составы и рисунки для этих коэффициентов. Изотермы среднего поля рассчитаны на CPU UMT. В остальных подразделах описана также отдельная проверка реализации с коэффициентами, восстановленными непосредственно из публикации.

Численный ориентир — ноябрьская рукопись v16, рис. 5 и табл. 1, и её приложение S1–S4, S6. В октябрьском комплекте `TiAl_phase_figure_sources_and_data_20261016` хранятся результаты другой серии CE + HA64. В её строке MTP при 1000 K составы равны 10.22835 и 21.68485 ат.% Al. В табл. 1 v16 для HA–MC указаны 15.28 и 20.61 ат.%. Для воспроизведения статьи используется вторая пара.

## Среднее поле

Статика использует все 20 округлённых коэффициентов из табл. S1 в указанном там порядке. Нормировка — сумма по неупорядоченным геометрическим кластерам, постоянный столбец на атом равен 1/2. В каждом кластере `mfa.py` явно подсчитывает число узлов предпочтительной подрешётки D0₁₉ и остальных трёх. Среднее произведения спинов при независимых заполнениях равно произведению соответствующих средних спинов. При атомной доле Al `c` код минимизирует по `c ≤ q ≤ min(4c, 1)`, `r = (4c − q)/3`, сумму энергии и `kBT [h(q) + 3h(r)]/4`, где `h(p) = p ln p + (1 − p) ln(1 − p)`. При фиксированном составе учитываются разупорядоченный минимум, упорядоченные минимумы и концы допустимого интервала.

На сетке `0 ≤ c ≤ 0.35` с шагом 0.0005 строится нижняя выпуклая оболочка. Для внутренних контактов уточняются равенства производных наклону хорды и проверяется, что прямая лежит ниже всей свободной энергии на сетке. Метка `window_edge` означает касание конца концентрационного окна. Численные ряды находятся в `results/mfa_contacts.csv` и `results/mfa_free_energy.csv`.

При 1000 K высоты красных столбцов на рис. 2 дают 18 гармонических поправок к парам и тройкам. Скрипт читает исходный растр 2100 × 840 непосредственно из DOCX, калибрует обе вертикальные шкалы по меткам осей и сохраняет коэффициенты с хешами источников. Масштаб одного пикселя составляет около 0.000145 эВ для пар и 0.000033 эВ для троек. Исходные значения `J₀, J₁` сохранены как выбор отсчёта при фиксированном объёме. Добавка `A + Bc` сдвигает абсолютную энергию и химический потенциал, сохраняя составы касания. `HA_Fig2_S1` обозначает оценку по растру и таблице. `fig2_static_pixel_eV` сохраняет синие столбцы для визуального контроля. Контакты статической кривой рис. 5а графически сняты с исходного растра 3840 × 3150; толщина линии — около 0.2 ат.% Al. Численные таблицы предпочтительны, когда они доступны.

Полная таблица взаимодействий позволяет независимо вычислить все три описания:

```powershell
python "$th/mfa.py" path/to/grid.npz "$th/results/grid" --temperatures 1000
```

В NPZ требуются `orbit_names` в порядке S1, возрастающие `volume_A3_atom`, `temperature_K`, `J_static` размера (V,20), `J_vib` размера (V,T,20). Энергии заданы в эВ на кластер; кратности учтены в корреляционных признаках. В узле опорного объёма берётся статика либо сумма со своим гармоническим вкладом. Для QHA при `p = 0` кубический сплайн с нулевыми вторыми производными на краях, как в MC, интерполирует коэффициенты по объёму. На каждом интервале сравниваются его концы и все внутренние стационарные точки при текущем заполнении подрешёток. Объём минимизируется до построения оболочки. Зависящие от объёма `J₀, J₁` должны поступать в полной таблице. Записываются `v(c)`, объёмы обеих фаз и диагностический флаг достижения края объёмной сетки. В `verify.py` это проверено на известном квадратичном минимуме и на монотонном профиле.

## Монте-Карло

`vcsgc.py` принимает CSV или CSV.GZ со столбцами `model,T_K,N,c0,kappa,delta_mu0_eV,replica,sweep,n_Al` и необязательным `m` для дальнего порядка. Каждая строка содержит одно измерение после уравновешивания. `n_Al` — целое число атомов, `delta_mu0_eV` — обменный химический потенциал (двойной потенциал в спиновой нормировке); `c0` — центр ограничения. В каждом окне вычисляются фактический средний состав и `Δμ = Δμ₀ − 2 kBT κ (⟨c⟩ − c₀)`. Повторные независимые траектории одного окна объединяются с учётом числа отсчётов. Скрипт интегрирует сохраняющую форму кусочно-кубическую интерполяцию PCHIP по измеренным средним составам, затем строит нижнюю выпуклую оболочку. Минимальная ширина разрешаемого участка — 0.005 доли Al. По сетке контактов шаг не превышает 0.005 ат.%. Все кандидаты сохранены, включая признак касания края измеренного интервала. Узкие интервалы вблизи верхнего окончания чувствительны к шагу окон и конечному размеру.

Каждая бутстрэп-выборка повторно выбирает временные блоки внутри каждого отдельного запуска. Средний состав и химический потенциал одного окна восстанавливаются из одних и тех же выбранных отсчётов. При одном исходном внутреннем интервале отчёт содержит долю повторных решений, охватывающих его середину, и условные процентили по этим решениям. В `window_correlations.csv` оценены времена интегрированной автокорреляции состава и порядка в отсчётах. Сопоставляйте их с фактической длиной блока. Эти процентили характеризуют длительность выборки внутри выбранной модели.

WHAM использует гистограммы целых `n_Al`, строит граф совпадающих непустых бинов и объединяет окна только при связности. Для связной системы логарифмы нормировок находятся по функции правдоподобия с фиксированной первой нормировкой, проверяется остаток её градиента. Свободная энергия WHAM сохраняется по дискретным составам. Слабо населённые хвостовые бины дают шумные контактные отрезки; для содержательного сравнения следует проверить конкретный интервал между теми же ветвями. Отсутствие внутреннего контакта на данной сетке — результат при конечном разрешении.

## Собственные ECI из ATAT и MTP

У `atomistic/atat/output` можно независимо проверить соответствие нативной геометрии и функций корреляции гамильтониану D0₁₉:

```powershell
python "$th/audit_atat.py" phase_reproduction/atomistic/atat/output "$th/results/native_cluster_audit.json"
```

Программа читает координаты ATAT, различает треугольники 222 по проекции центра, проверяет полином среднеполевого усреднения каждой орбиты через четыре эквивалентных выбора предпочтительной подрешётки. Также проверяются контрольные суммы всех выбранных `str.out`, знак Ti/Al и нормировка каждого столбца нативного `corr.out`. Порядок строк в нативном `clusters.out` отличается от S1.

В `umt/sweep.py` по содержимому входного файла выбирается физический расчёт. Один объём с фононами даёт одинаковую маску для статики и HA. Полная девятиобъёмная таблица даёт QHA. Статика на всех 46 структурах до исключения фононно-неустойчивых состояний хранится как диагностическая версия. Для физического сравнения трёх моделей используются статические коэффициенты с маской HA. Типичные команды запуска из корня проекта:

```powershell
python phase_reproduction/cluster/umt_job.py submit --cpus 6 --memory 4 --minutes 60 new-mfa-run "$th/umt/job.sh" "$th/umt/sweep.py" "$th/mfa.py" phase_reproduction/atomistic/hcp_orbits.py phase_reproduction/atomistic/atat/ha_fit/grid.npz
python phase_reproduction/cluster/umt_job.py status new-mfa-run
python phase_reproduction/cluster/umt_job.py fetch new-mfa-run grid_mfa_contacts.csv grid_mfa_free_energy.csv.gz validation.json
```

В имени запуска используйте уникальные строчные буквы, цифры и дефисы. Готовые результаты каждого запуска содержат SHA-256 таблицы ECI, версии NumPy/SciPy, температуры, идентификатор Slurm и таблицу свободных энергий на 701 составе. `compare_atat.py` принимает одну или несколько таблиц MFA и отдельно JSON обработанных собственных MC-траекторий. Составы в сравнении указаны в ат.% Al.

### Верхние сечения и выбор ветви

Для проверки верхних сечений S3 в ячейке на 5120 узлах центры `c0` пройдены от 0.02 до 0.36 через 0.005. Шаг 0.005 явно указан в S3 для статики при 1600 и 1650 K. Для прочих верхних температур текст v16 не задаёт точную сетку центров; полный диапазон и единый мелкий шаг — выбор этой реализации.

Широкая сетка иногда выявляет несколько внутренних сегментов нижней выпуклой оболочки. Например, химический порядок может сначала увеличиваться в Ti-богатом твердом растворе, а затем снова уменьшаться при более высоком содержании Al. Все сегменты шириной строго более 0.5 ат.% Al остаются в `TI_contacts`. В уточняющих сериях S3 программа интерполирует измеренный в окнах дальний порядок на обоих концах сегмента. Направление записывается, если разность по модулю превышает удвоенную сумму блочных стандартных ошибок оценок на концах. Для Ti-богатого перехода α→α₂ в сводной таблице используется единственный внутренний сегмент с подтверждённым ростом порядка. На диаграмме основные изотермы 768 образуют разорванную линию в точках, где контакт не разрешён. Результаты 5120 показаны отдельными пустыми маркерами.

В каждой бутстрэп-выборке независимые временные блоки пересобираются отдельно по окнам. Для **каждого** исходного внутреннего сегмента записываются доля повторных отрезков, охватывающих его середину, и условные процентили. `upper_contacts.py` собирает составы, ширины, статистику разрешения и времена автокорреляции верхних изотерм в `atat_upper_comparison.csv`. Если корреляция параметра порядка длиннее блока, интервал отражает только выбранную процедуру повторной выборки. `mixing.py` сравнивает адресные длинные старты (случайный и упорядоченный) с исходной траекторией и оценивает изменение контакта при замене лишь проверенного окна.
