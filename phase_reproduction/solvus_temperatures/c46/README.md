# Классический C46 при 600 и 1273,15 K

## Гамильтониан и ансамбль

Использованы 46 декораций исходного C46, авторские статические энергии MTP Qi, 20 орбит и исходное отношение осей ГПУ \(c/a=4{,}6046/2{,}9446\). На каждом из девяти объёмов от 16,2510 до 19,3629 Å³/атом сохраняются исходные матрица корреляций, маски обучения и фононной устойчивости. Из 409 устойчивых сочетаний структуры и объёма в подгонку входят 346, в контроль — 63. Коэффициенты интерполируются по объёму кубическими сплайнами с граничными условиями *not-a-knot*. Симметричные пробы изменения объёма принимаются по полной квазигармонической энергии при \(p=0\).

Классическая гармоническая свободная энергия равна \(\sum_\nu k_\mathrm BT w_\nu\ln[\hbar\omega_\nu/(k_\mathrm BT)]\), где веса нормированы на атом. Поэтому из сохранённых \(F_\mathrm{cl}(1000)\) и \(g=\sum_\nu w_\nu\) получаем

\[
F_\mathrm{cl}(T)=\frac{T}{1000}\,F_\mathrm{cl}(1000)
-g k_\mathrm BT\ln\!\left(\frac{T}{1000}\right).
\]

Для каждого фононного спектра использованы собственные \(g\) и метка при 1000 K, ранее восстановленные из температурных таблиц автора. Проверка процедуры на независимом наборе спектров, для которого доступны сами частоты, дала максимальную ошибку 7·10⁻¹³ эВ/атом. При 1000 K новая реализация воспроизводит классические и квантовые колебательные коэффициенты прежнего расчёта с максимальным расхождением 5,6·10⁻¹⁶ и 1,8·10⁻¹⁴ эВ соответственно. При 600 K квантовые коэффициенты взяты с авторского температурного узла. Для 1273,15 K использован сплайн по исходной сетке через 25 K. Удвоение температурного шага интерполяции меняет предсказания по 46 декорациям менее чем на 4·10⁻⁹ эВ/атом. ## Оценка границ

В каждом проходе VCSGC Монте-Карло выполняются \(N\) попыток изменить химический сорт случайно выбранного узла и одна объёмная проба. Для доли Al \(x\) добавка к энергии равна \(N[k_\mathrm BT\kappa(x-c_0)^2-\mu_0 x]\), где \(\kappa=100\). Каждое окно даёт точку \(\mu(\langle x\rangle)=\mu_0-2k_\mathrm BT\kappa(\langle x\rangle-c_0)\). Поле сопряжено с заменой одного Ti на Al и выражено в эВ. Химический потенциал интерполируется PCHIP, а его первообразная даёт свободную энергию с произвольной константой. Касательная касается обеих ветвей, проходит ниже всей восстановленной кривой и связывает внутренние точки с разностью концентраций не менее 0,5 процентного пункта. Порядок \(m\) определяется по заполнению четырёх подрешёток D0₁₉. Для идеального Ti₃Al \(m=1\).

На 5120 узлах (16×16×10 двухатомных ячеек) использованы 52 окна при 600 K и 51 при 1273,15 K с шагом \(c_0\) 0,005, 3000 проходов на уравновешивание и 9000 производственных с записью каждых десяти. На 768 узлах (8×8×6) шаг равен 0,01, по 26 окон на температуру, 1500+4500 проходов с записью каждых пяти. В глобальном весе квантового перевзвешивания участвует разность полных энергий ячейки, восстановленных из мгновенных объёмов и сумм по всем орбитам. Условные 95%-е интервалы получены по 384 блочным выборкам. Длина блока учитывает автокорреляцию состава, порядка, объёма, разности энергий и взвешенного состава. Интервалы описывают статистику выборки при фиксированных размере ячейки, сетке окон и модели.

## 1273,15 K

На 5120 узлах достигнуты средние составы от 13,979 до 36,858 ат.% Al, включая обе экспериментальные границы. Химический потенциал возрастает на каждом из 50 интервалов, минимальный прирост равен 6,53 мэВ. Строгая монотонность сохраняется во всех 384 блочных выборках. Максимальный средний порядок \(m=0{,}0731\) наблюдается при 30,99 ат.% Al. На 768 узлах достигнуты 13,982–36,837 ат.% Al, минимальный прирост между соседними окнами более редкой сетки равен 13,24 мэВ, максимум \(m=0{,}2433\) при 29,62 ат.% Al. Уменьшение глобального порядка с ростом размера согласуется с существенным вкладом флуктуаций подрешёточных заполнений.

На двух размерах общая касательная α/α₂ с шириной от 0,5 п.п. не разрешается. Переход к квантовому гамильтониану перевзвешиванием даёт тот же результат (минимальная доля Киша 0,966 на 5120 узлах). Сетка по составу, конечный объём и длительность расчёта ограничивают чувствительность к слабому переходу. Оценить высокотемпературные равновесные составы или критическую температуру по этой изотерме нельзя. В авторской квантовой серии при 1200 K найдена пара 23,464/24,908 ат.% Al, при 1225, 1250 и 1300 K отдельные контакты также не разрешились. В эксперименте при 1273,15 K Кайнума и соавторы получили 19,5±0,5 и 23,0±0,3 ат.% Al. [Изотерма и параметр порядка, 5120 узлов](T1273.15/c5120/window_stats.csv) · [Блочная оценка, 5120 узлов](T1273.15/c5120/result.json) · [Контроль на 768 узлах](T1273.15/c768/result.json) · [Экспериментальная методика](../experiment.md).

Контроль стартового состояния на 768 узлах также выполнен независимой серией из 26 окон при 1273,15 K. При случайной инициализации получено \(m_{\max}=0{,}218\), все соседние приращения \(\mu\) положительны во всех 384 блочных выборках, минимальный прирост по средним равен 12,67 мэВ. При 600 K разность между случайным и упорядоченным стартом составляет −0,005 и +0,057 п.п. для левой и правой границ. ## Химическое среднее поле на том же C46

В приближении Брегга–Вильямса при фиксированной доле Al варьируется заполнение одной подрешётки. Условие баланса состава задаёт одинаковую заполненность трёх остальных. Для каждого состава свободная энергия минимизируется по параметру порядка и объёму. По полученной кривой строится общая касательная. Оба найденных объёма находятся внутри исходной таблицы. Рост разницы с Монте-Карло при повышении температуры показывает, насколько результат чувствителен к учёту корреляций химических заполнений.

| T, K | Классический C46, MFA, ат.% Al | Квантовый C46, MFA, ат.% Al |
|---:|---:|---:|
| 600 | 2,468 / 24,276 | 2,493 / 24,265 |
| 1273,15 | 15,438 / 22,051 | 15,490 / 22,066 |

При 1273,15 K замена колебательной статистики при одинаковом химическом приближении меняет левую границу на 0,052 п.п., правую на 0,015 п.п. Классическое среднее поле даёт ширину 6,613 п.п.; экспериментальная ширина Kainuma и соавт. составляет 3,5 п.п. ## Воспроизведение

Из корня проекта расчёт на 5120 узлах при 600 K можно повторить в новом каталоге следующими командами. Десятичная точка в аргументе 1273.15 сохраняется в MC и в выходных записях. Манифест каждой серии содержит старт, зерно, длину траектории, шаг записи и все центры окон.

~~~powershell
$d = 'phase_reproduction/solvus_temperatures/c46'
python "$d/prepare.py" AUTHOR_PACKAGE 600 repeat5120 --size 5120 --start ordered --eq 3000 --prod 9000 --stride 10 --seed 5120123
python phase_reproduction/classical_c46_1000/run_local.py "$d/T600/repeat5120" tmp/classical_vcs.exe --workers 3
python "$d/analyze.py" "$d/T600/repeat5120"
~~~

Каталог AUTHOR_PACKAGE содержит structures/index.csv и models/HA_QHA/volume_temperature_coefficients.npz. Хеши из [проверки MC при 1000 K](../../classical_c46_1000/mc_validation.json) позволяют сверить двоичный файл с [исходным C++ драйвером](../../mc/vcs.cpp).
