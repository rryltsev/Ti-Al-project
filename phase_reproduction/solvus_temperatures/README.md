# Ti–Al. Сосуществование α и α₂ при 600 и 1273,15 К

В каталоге собраны расчёты при нулевом давлении на опубликованном MTP Qi, а также согласованные по температуре расчёты C46 и CALPHAD. Для верхней изотермы выбрана экспериментальная температура 1000 °C. Кайнума и соавторы измерили здесь обе границы после 200-часового отжига диффузионной пары. Ближайшая следующая изотерма в той же таблице — 1323,15 К. [Экспериментальные точки и источники](experiment.md) · [Первичная статья, табл. 1](https://doi.org/10.1016/0966-9795(94)90018-3).

## Результаты и первичные данные

При **600 К** получено **5,866 [5,798–5,928] / 24,265 [24,241–24,285] ат.% Al** в α и α₂ на 1400 атомах со свободным отношением осей и `W < 0.40`. Это условные 95%-е интервалы. На 768 атомах при фиксированном авторском отношении осей прямой MTP даёт 7,574/23,818, а классический C46 на 5120 узлах — 4,548/24,104. CALPHAD Liang при этой температуре даёт 10,930/20,037.

При **1273,15 К** прямой MTP не разрешает два равновесных состава в экспериментальном интервале 19,5–23,0 ат.% Al. Профили двух больших ячеек проверены при независимых начальных состояниях. Классический C46 даёт монотонную химическую изотерму. В эксперименте равновесный интервал имеет ширину 3,5 п.п., в CALPHAD Liang — 3,85 п.п. Вывод относится к ограниченному кристаллическому ансамблю. Для определения температуры замыкания сольвуса нужны промежуточные изотермы.

- [Отчёт PDF](report/TiAl_600K_1273K.pdf) и [самодостаточный исходник XeLaTeX](report/TiAl_600K_1273K.tex) содержат метод, сравнение и проверки сходимости.
- [Численные результаты](results.json) фиксируют источники данных для каждого размера ячейки и контрольные суммы. В записях `Al_at_pct` состав дан в атомных процентах. В исходных профилях `x_Al`, `x_alpha`, `x_alpha2` — атомные доли. Величина `null` в итоговом поле для состава означает, что определить два фазовых контакта по этой изотерме не удалось.
- Для прямого MTP сохранены [сводка серий UMT](atomistic/series_summary.csv), [сведения об исходных файлах и архивах](atomistic/provenance.json), [проверка температурного драйвера](atomistic/temperature_validation.json) и [исходные траектории](atomistic/series). Внутри каждой серии `windows.csv` задаёт размер, начальное состояние, зерно, поле, смещение и жёсткость зонтика, число проходов и частоту записи. `window_status.json` фиксирует завершение каждого окна. `burn` — число начальных проходов, `sweeps` — последующее число производственных проходов.
- [Отдельная проверка 600 К по траекториям без зонтика](analysis/600_independent_endpoints.json) содержит условные средние по каждой фазе, приведённые к полю сосуществования. Число запусков в фазе не используется как её равновесный статистический вес.
- При 1273,15 К на 1400 атомах и поле 3,42 эВ средний параметр локального порядка по блокам 4×4×3 составил 0,152 и 0,206 в двух конечных снимках. При перестановках с сохранением суммарного заполнения каждой подрешётки средние значения равны 0,114 и 0,127. Это указывает на локальные корреляции и совместимо с однопиковым распределением состава. [Проверка пространственных корреляций в прямых траекториях](analysis/1273_n1400_unbiased_domains.json).
- [Кластерное разложение C46](c46/README.md) включает классическую и квантовую колебательную статистики, химическое среднее поле, окна VCSGC, сгущение сетки и блочную оценку интервалов.
- [Контакты CALPHAD](calphad/liang_contacts.csv) получены при точно заданных температурах и нулевом давлении. [Параметры CALPHAD](calphad/metadata.json) включают версию движка, хеш базы и правило выбора Ti-богатой ветви. [Экспериментальная таблица в ат.% Al](calphad/kainuma_table1.csv) содержит также длительность отжигов.

## Воспроизведение анализа

Для прямого MTP нужны Python с NumPy и SciPy и сохранённые оконные траектории. Из корня проекта, в PowerShell, можно повторить основной расчёт при 600 К без доступа к кластеру. Каталог вывода в примере временный.

```powershell
$s = 'phase_reproduction/solvus_temperatures'
$py = 'blind_pilot/.venv-local/Scripts/python.exe'
$a = "$s/atomistic/series"
New-Item -ItemType Directory -Force tmp/solvus_checks | Out-Null
& $py "$s/analysis/isotherm.py" "$a/at600-n1400-a/windows.csv" "$a/at600-n1400-b/windows.csv" --bootstrap 192 --seed 26713 --bandwidth 0.04 --field-bounds 3.143 3.170 --out tmp/solvus_checks/600.json
& $py "$s/analysis/endpoint_check.py" tmp/solvus_checks/600.json "$a/at600-n1400-pure/windows.csv" --out tmp/solvus_checks/600_independent.json
```

Для анализа при 1273,15 К `isotherm.py` восстанавливает распределения и средние по полю. Сценарий `analysis/response.py` на тех же окнах определяет восприимчивость и моды состава. [Каталог команд с точными параметрами и окнами по каждому размеру](analysis/reproduce.py) поддерживает `--list` и `--show`. Объединяются окна одной температуры, размера, механического условия и ограничения смещений. Для сообщения двух контактов требуются воспроизводимые фазовые бассейны с различимыми составами при увеличении размера. Указание `--quick` строит только профиль по полю.

Сценарий `report_sources/make_report.py` формирует готовый исходник по `results.json` и проверенным профилям. Готовый `.tex` включает координаты рисунков и таблицы, его можно дважды скомпилировать `xelatex` без каталога с траекториями.
