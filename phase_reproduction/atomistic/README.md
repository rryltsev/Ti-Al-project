# Ti–Al от MTP до кластерной модели

Версия v16 рассматривает α и α₂ на общей ГПУ-решётке. На вход статистическому расчёту поступают статические и колебательные коэффициенты, подогнанные по энергиям химических конфигураций. Релаксации и фононы здесь рассчитывает опубликованный потенциал Qi и соавт. на CPU. Типы MLIP-CFG идут в порядке 0 = Ti, 1 = Al. SHA-256 использованных весов `704f7fd900c7446286066b741084c30ebc7fcf26e5b9b8fd2f29a18ba4ffd661`.

## Геометрия и исходные структуры

`hcp_orbits.py` восстанавливает 20 членов из таблицы S1. Для перечисления оболочек отношение осей равно 1.6, для MTP геометрия имеет точный опорный объём 17.288329847774033 Å³/атом и отношение осей 4.6046/2.9446 из округлённых параметров статьи. Классы треугольников 222 разделены по тому, совпадает ли центр с проекцией узла соседнего слоя. Функция `features` суммирует произведения спинов по каждому геометрическому вхождению и делит на число атомов. Постоянная координата равна 0.5. Энергия на атом равна скалярному произведению признаков и коэффициентов. `STATIC_S1` содержит печатные округлённые коэффициенты. Для исходной химической ячейки общего вида используйте `features_for_parent_sites(S, sites, spins)` с целочисленной матрицей суперячейки и индексами на идеальной родительской решётке до релаксации.

`make_pilot.py` создаёт 18 периодических структур α-Ti и Ti₃Al-D0₁₉ для первичной проверки вида, объёма и единиц энергии. Силы на идеальных Ti-позициях в D0₁₉ могут быть ненулевыми. Энергии до и после внутренней релаксации приведены раздельно. Базальная решётка использует положительный угол 60°, второй базисный узел имеет координаты (⅓,⅓,½), в D0₁₉ предпочтительная подрешётка смещается на (1,1) по модулю 2 между слоями.

Исходные 46 декораций и их полные корреляции в папке PD отсутствуют. В `design` лежит **независимая реконструкция выборки** с 39 обучающими и семью контрольными ячейками. Известны точные химические прототипы чистого Ti и D0₁₉. В дополнительные 64-узельные пары включены 17, 20 и 22 атома Al, как в S1. Микросостояния выбраны заново. Сначала фиксируются обязательные пары и контроль, затем остальные обучающие строки выбираются по информационному выигрышу геометрической матрицы. Для этих строк получен ранг 20, число обусловленности 126.04. Манифест сохраняет SHA-256 каждой идеальной ячейки, исходные признаки, разбиение и параметры для всех 414 заданий. Повторить генерацию можно в новой директории.

```bash
python make_pool.py new_design
python make_random_anchor.py new_anchor
```

Отдельный `random_anchor` имеет 16 Al на 64 узлах. Название в S2 сообщает seed 20261013; генератор случайных чисел и порядок выбора авторов не переданы. В этой реализации фиксированы PCG64, выбор без возвращения и нумерация узлов. Поэтому разность свободных энергий двух реализаций случайного сплава может различаться.

## Вычисление прямых меток на CPU

Нужны NumPy, SciPy, Phonopy и последовательный исполняемый файл MLIP. Проверено на UMT с MLIP 3 и Phonopy 4.8.2. Один запуск обрабатывает одну химическую конфигурацию и один объём; путь вывода должен быть новым.

```bash
python label_cell.py --prototype Ti3Al_D019 --ratio 1.0 --supercell 5 5 6 \
    --model /path/to/fitted.mtp --mlp /path/to/mlp --output D019_v1.00
python label_cell.py --cell design/cells/train_02.cfg --ratio 1 --supercell 2 2 3 \
    --model /path/to/fitted.mtp --mlp /path/to/mlp --output labels/train_02_v1.00
```

Каждая CFG для `--cell` содержит одну ячейку при опорном объёме. Программа изотропно масштабирует её при сохранении формы, релаксирует координаты до максимума нормы силы на атоме 10⁻⁵ эВ/Å и ведёт фиксированный порядок видов. При необходимости только статической метки добавьте `--static-only`. Для полного маршрута Phonopy создаёт смещения ±0.01 Å, `symprec=1e-5`, примитивная матрица единичная. Силы несмещённой суперячейки вычитаются. Программа симметризует матрицу силовых постоянных и проверяет три переноса в Γ. Γ-центрированные сетки 16³ применяются к ячейкам до 32 атомов, 6³ — к 64-атомным. В `mesh.npz` сохранены частоты в ТГц, веса и q-точки, в `raw_forces.npz` — исходные, включая невозмущённые, силы. Свободная энергия содержит нулевую энергию и квантовую тепловую сумму по положительным частотам с тепловым порогом 10⁻⁵ ТГц, результат нормирован на атом. При неположительной внутренней частоте сохраняется диагностика устойчивости.

Референсные повторы Ti 8×8×6 и D0₁₉ 5×5×6 указаны в S8 для фононной проверки. У статьи нет индивидуальной матрицы повторов каждой исходной ячейки для термодинамической подгонки в переданной папке. Выбор повторов независимой серии записан в `design/jobs.csv`. Директория результата включает неокруглённую вычисленную метку, модель, максимальную силу, частотную диагностику и температуру.

## Подгонка и контроль

Соберите директории `label_subdir` из `jobs.csv` в одной папке. Для указанного набора объёмов необходима запись результата на каждую конфигурацию, включая физически неустойчивые состояния. Нестабильные строки исключаются из обеих подгонок одновременно. Метод наименьших квадратов использует одинаковый вес структуры. Команда сохраняет коэффициенты, поконфигурационные остатки, среднеквадратическую ошибку контроля и LOO на обучении.

```bash
python fit_eci.py design labels fitted                 # полная сетка
python fit_eci.py design labels fitted_HA --ratios 1   # гармонический срез
python fit_eci.py design labels fitted_E --static-only --ratios 1
```

`grid.npz` содержит массивы `J_static[volume,orbit]`, `J_vib[volume,T,orbit]`, `volume_A3_atom`, `temperature_K` и `orbit_names`. Для HA берётся срез при опорном объёме, для QHA интерполируются взаимодействия по объёму при фиксированной температуре. Статический диагностический режим создаёт отдельный `static_grid.npz` и помечает отсутствие маски фононной устойчивости. Ошибка валидации относительно меток MTP относится к кластерному разложению.

`anchor_qha.py` применяет к прямым MTP-меткам двух упорядоченных состояний кубический сплайн с нулевым внешним давлением. Все внутренние стационарные точки сравниваются с концами объёмной сетки. В `ordered_qha.csv` сохраняются условные свободные энергии и объёмы **отдельных конфигураций**. Контроль S2 в `comparison.json` сопоставляет 600 K для D0₁₉ с печатными 16.97 Å³/атом и −2.16 мэВ/атом. Фазовая граница затем требует статистической выборки состава.

```bash
python anchor_qha.py --archives ../cluster/runs/ha-pilot-01/outputs/results.tar.gz \
    ../cluster/runs/ha-volumes-01/outputs/results.tar.gz \
    --efs ../cluster/runs/pilot-01/outputs/efs.result --manifest pilot/pilot_manifest.csv --out results
```
