# Выборка ATAT и эффективные взаимодействия Ti–Al

Полная повторная серия на UMT дала 414 релаксированных структур с фононами, по 46 на каждый из девяти объёмов. В [файле QHA](qha_fit/grid.npz) находятся статические коэффициенты и температурный ряд 600–1800 K по всем орбитам. Из 414 точек устойчивы 396. В совместной подгонке использованы 333 обучающие точки, остальные 63 устойчивые точки (7 × 9) послужили независимым контролем. В порядке возрастания объёма приняты 37, 37, 37, 37, 38, 38, 38, 37 и 34 обучающих точки. Нестабильные конфигурации перечислены в [сводке для девяти объёмов](qha_fit/range_summary.json). По семи контролям наибольшая RMS-ошибка аппроксимации колебательной энергии составила 5.58 мэВ/атом на полной сетке, 1.54 мэВ/атом в области 600–1200 K и 0.96–1.06 опорного объёма.

В `output` зафиксированы 39 обучающих и семь контрольных структур. **40 структур** с числом атомов до 12 получены прямым перечислением `genstr`, включая чистый α-Ti и Ti₃Al-D0₁₉. Ещё **шесть структур** по 64 атома построены `mcsqs` при фиксированной суперячейке 4×4×2 и заданных ограничениях заполнения. Это независимый набор в геометрическом и энергетическом базисе статьи. Позднее переданные авторские координаты и индексы сохранены в [комплекте C46](../../author_package/START_HERE.md).

В `selected/<id>/str.out` находится исходная структура ATAT, в `selected/<id>/corr.out` — нормированные корреляции в нативном порядке отобранных орбит. `cells/<id>.cfg` содержит ту же декорацию при физическом объёме. В `design.csv` есть исходный номер `genstr` либо имя запуска `mcsqs`, матрица химической суперячейки относительно родительского базиса, число Al, назначение в train/control, контрольные суммы и взвешенные признаки в порядке таблицы S1. Исходные параметры шести больших структур записаны в соседнем каталоге `../atat_large`.

## Перечисление и отбор

Использован ATAT 3.52. Авторский `genstr` перечисляет симметрически неэквивалентные декорации бинарной ГПУ-решётки. Порядок в `lat.in` равен Ti,Al. Нормированные векторы имеют длины 1,1,1.6 и угол 60° между базальными осями. Фактические входы команд и хеши исполняемых файлов находятся в `output/job.sh` и `output/binaries.sha256`. [Опции genstr](https://axelvandewalle.github.io/www-avdw/atat/manual/node73.html). [Команды corrdump](https://axelvandewalle.github.io/www-avdw/atat/manual/node35.html).

```bash
genstr -l=lat.in -n=12 -sig=14 > enum.out
corrdump -l=lat.in -2=1.90 -3=1.90 -clus -sig=14
corrdump -l=lat.in -c -s=enum.out -sig=14 > correlations.out
```

При максимуме 10 атомов получены 984 структуры, включая 186 в Ti-богатом диапазоне. Два столбца геометрически различных троек 222 совпали на всех 186 точках. Максимальный ранг равнялся 19. При пределе 12 атомов появились независимые строки. Из 5777 структур 1174 имеют до 35 ат.% Al. Для 944 из них подобраны диагональные повторы с 504–1728 атомами и расстоянием между противоположными плоскостями суперячейки больше 4 радиусов отсечения даже на минимальном объёме. Последнее условие уменьшает наложение периодических образов силовых констант MTP. В итоговом наборе силовые ячейки содержат 720–1470 атомов.

При отборе фиксируются крупные пары на 17 и 20 Al в обучении и пара на 22 Al в контроле. Пять малых контролей выбираются заранее на разных составах. Обучение дополняется по приросту информации корреляционной матрицы с фиксированными чистым Ti и D0₁₉. Ранг матрицы 39×20 равен 20, число обусловленности 104.27. `pool.csv` сохраняет признаки всего перечисления и принадлежность допустимому неповторяющемуся набору. Протокол отбора использует только геометрию и состав.

```bash
python select_cells.py ../../cluster/runs/atat-enum-12-01/outputs/enum.tar.gz \
    another_design --fixed ../atat_large/cells64
```

## От корреляций к энергии

Радиус перечисления дал 33 нативные орбиты до троек. Программа отбирает 20 членов S1 по порядку, номерам оболочек и расположению треугольника относительно соседнего слоя. Оба типа 222 сохранены. Максимальная абсолютная разница между `corrdump` с нормировкой S1 и независимым перечислением кластеров в 46 периодических ячейках составила 5.34×10⁻¹⁴. При фиксированном объёме координаты атомов релаксируются в MTP, а геометрические корреляции берутся до релаксации.

`output/native/clusters.all.out` содержит 33 орбиты. В `output/clusters.out` сохранены 20 нативных блоков ATAT. Их последовательность отличается от S1. Для каждого взаимодействия с корреляцией ρ и кратностью m из `clusters.out` вклад в энергию одного атома равен mJρ/2. Для пустого кластера это J₀/2. В `fit_eci.py` используется одинаковый вес структуры после нормировки MTP-энергии на один атом.

```bash
python ../fit_eci.py output /path/to/static/results.tar.gz static_fit --ratios 1 --static-only
python export_eci.py output static_fit/static_grid.npz eci_static --corrdump /path/to/corrdump
```

В экспортной директории `eci.per_cluster_eV` хранит физические J в порядке нативного `clusters.out`, а `eci.out` содержит J/2, чтобы `corrdump -c -eci=eci.out -s=selected.out` выдал эВ/атом. В `predictions.csv` можно сверить каждую из 46 структур. Для HA добавьте при экспорте `--temperature 1000` и укажите `grid.npz` полного фитирования. Для фиксированного среза объёма в QHA используется `--ratio` вместе с температурой.

Новый статический расчёт при опорном объёме дал для первых двух оболочек +51.682 и +36.004 мэВ/кластер. В S1 опубликованы +49 и +36 мэВ/кластер. Все 20 результатов LLS находятся в [таблице взаимодействий](eci_static/interactions.csv). Среднеквадратическая ошибка на семи отложенных структурах составила 2.320 мэВ/атом, LOO на 39 обучающих — 8.166 мэВ/атом. Для контрольной пары 22 Al на 64 узлах MTP даёт разность между случайным и D0₁₉-подобным состояниями +51.519 мэВ/атом, CE — +55.426 мэВ/атом. Этот статический срез получен до проверки общей маски фононной устойчивости. Исходник — архив `../../cluster/runs/atat-static-02/outputs/labels.tar.gz`.

Все 46 фононных расчётов при опорном объёме завершены. На собственной выборке `train_26` и `train_30` дали мнимые внутренние частоты −1.3155 и −0.1786 ТГц. После исключения двух строк осталось 37 обучающих и семь контрольных структур. Для сравнения с гармоническим расчётом используйте [статические коэффициенты на общей маске](eci_static_masked/interactions.csv). Полные взаимодействия при 1000 K находятся в [таблице HA](eci_HA1000/interactions.csv), сетка 600–1800 K с шагом 25 K — в `ha_fit/grid.npz`. В сечении 1000 K RMSE по семи контролям составляет 0.837 мэВ/атом для колебательной части и 2.724 мэВ/атом для суммы E+Fvib. Для пары на 22 Al ошибка разности колебательных свободных энергий составляет −0.237 мэВ/атом, а для полной энергии +3.631 мэВ/атом. По исходным данным v16 при опорном объёме устойчивы все 39 авторских обучающих структур.

Для всех девяти объёмов первый архив передаётся в позиционном аргументе `labels`, остальные через `--additional-labels`. Совместные маски устойчивости и результаты валидации описаны в [документации расчёта меток](../README.md). При передаче коэффициентов сравнивайте порядок орбит по полям `native_names` в экспортном JSON и `orbit_names` во входном NPZ.
