# Прямые изотермы для ячейки из 2304 атомов

Каждый каталог в `series/` содержит манифест отдельного задания. Фактические `T_K`, `cap`, `mu_eV`, сила пружины `K_eV`, центр `q0`, начальное состояние и длины прогрева и измерения записаны для каждой цепочки. Все цепочки согласованы с решёткой 12 × 12 × 8 HCP, свободным отношением `c/a` и нулевым внешним давлением. Везде использован MTP с SHA-256 `704f7fd900c7446286066b741084c30ebc7fcf26e5b9b8fd2f29a18ba4ffd661`.

При 1243 K начальная сетка каждого ансамбля включает семь полей от 3.510 до 3.580 эВ на замену Ti → Al. На каждом поле поставлены 14 зонтиков по (Q) и две независимые цепочки с повтором центров при противоположных начальных состояниях. На 1242, 1244 и 1245 K начальная сетка содержит по пять полей. Выборки с `K_eV=0` имеют отдельные манифесты и парные старты `ordered` и `random`. Новые задания имеют префикс `cg`. Старый расчёт при 1245 K и (W=0.40) хранится в `solvus_closure` и может использоваться как независимая проверка.

Серверные каталоги находятся в `/home6/u3129/tial-cage2304-20261126/` на UMT, в них сохраняются `job.id`, журналы Slurm и результаты. Ниже приведены команды из корня проекта TiAl.

После проверки центральных полей при 1242–1244 K сетка для (W=0.35) при 1243 K расширена до 3.458–3.624 эВ. Дополнительные триплеты полей 3.520, 3.545 и 3.570 эВ поставлены при 1254, 1262 и 1269 K для (W=0.35) и при 1239 K для (W=0.40). Серии `cg40r43a/b/c` при 1243 K и (W=0.40) повторяют проверку в трёх полях 3.530, 3.545 и 3.560 эВ с новыми начальными состояниями и длиной 700 + 1800 свипов.

```powershell
python -B phase_reproduction/solvus_cage2304/atomistic/cage_runs.py checkpoint
python -u -B phase_reproduction/solvus_cage2304/atomistic/harvest.py
```

Первая команда записывает снимок Slurm с контрольной суммой на ПК и на сервер. Вторая получает до шести завершённых архивов за одно SSH-соединение, отдельно сверяет SHA-256 каждого и сохраняет готовые траектории. Эту команду можно повторить после перерыва. Для последовательной выгрузки с продолжением частичного файла и тем же итоговым аудитом используется

```powershell
python -u -B phase_reproduction/solvus_cage2304/atomistic/cage_runs.py resume
```

В результате создаются `series_summary.csv`, `slurm_accounting.csv` и `provenance.json`. Необязательные промежуточные фрагменты траекторий находятся отдельно в `prefixes/`. Они позволяют выбрать дополнительные поля и температуры до окончания задания. Для итоговых расчётов используются полные `series/*`; соответствие фрагментов финальным записям проверяет `prefix_audit.json`.
