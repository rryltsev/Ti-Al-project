# Прямые изотермы при двух ограничениях смещения

Для вектора связи идеальной деформированной ячейки \(\mathbf r\) и смещения \(\mathbf u\) с удалённым общим переносом код вычисляет \(2\mathbf u\!\cdot\!\mathbf r/|\mathbf r|^2\). Параметр \(W\) — максимум этих проекций по атомам и двенадцати соседним направлениям. Граница 1 достигается на плоскости, проходящей через середину связи. Использованные пределы 0,35 и 0,40 соответствуют долям расстояния до такой плоскости при осевом смещении вдоль выбранной связи.

Для каждого значения безразмерной границы \(W_{\max}\), каждой температуры и ячейки из 2304 узлов строится отдельная модель. Вес MBAR для переключений Ti/Al и классических смещений зависит от числа Al и свёрнутого параметра четырёхподрешёточного порядка \(Q\). Пружина зонтика имеет энергию \(K(Q-Q_0)^2/2\). Разность химических потенциалов \(\mu\) входит в полуканонический вес через \(+\beta\mu k\). Поиск проводится в замкнутом интервале полей, для которых получены полные зонтичные наборы. В частности, каждое приводимое поле контакта сопровождается парой фактических полей, его ограничивающих.

Основная граница структурных бассейнов равна \(q_c=0{,}37\). Также используются \(0{,}32;0{,}42;0{,}47;0{,}50\) и одно значение из минимума прямого распределения \(P(Q)\) при центральном максимуме отношения весов. В каждом случае разделитель сохраняется при сканировании поля. Два контакта соответствуют противоположно направленным пересечениям нуля функции \(S=\ln(P_{Q>q_c}/4P_{Q\le q_c})\), с поправкой на четыре трансляционных варианта упорядоченной фазы. Составы двух фаз равны условным средним \(k/N\). Для каждого контакта вычисляются заселённости, локальный барьер от меньшего пика и эффективное число наблюдений в обоих бассейнах. Ширина указывается со знаком \(x_{\alpha_2}-x_\alpha\).

В точке внутреннего максимума \(\partial_\mu S=N(x_{\alpha_2}-x_\alpha)/(k_BT)=0\). Поэтому исследуется также структурное различие при равных составах. Локальный температурный наклон при фиксированном поле вычисляется по разности полных полуканонических энергий \(N\Delta(u-\mu x)/(k_BT^2)\); при внутреннем поле максимума он совпадает с производной оптимизированной величины. Экстраполяция с использованием одного наклона предназначена для выбора следующих температур.

Серии с нулевой пружиной дают независимый контроль и счёт переходов между ядрами \(Q<0{,}35\), \(Q>0{,}60\). Основной MBAR использует только положительные пружины. При одинаковой пружине сравниваются средние и временные половины траекторий с разными начальными состояниями. Статистические интервалы 95% для основных оценок вычисляются по 64 независимым наборам временных блоков с повторным решением MBAR. Для существования каждой ветви и для двух ветвей одновременно отдельно приводится доля повторов со скобкой в пределах моделировавшихся полей. Интервалы координат и ширин условны по наличию корня. Файлы `fields` дают независимый MBAR в каждом непосредственно моделировавшемся поле, включая блочные интервалы и контроль совпадающих зонтиков.

Из корня проекта:

~~~powershell
$env:OPENBLAS_NUM_THREADS='1'
.\blind_pilot\.venv-local\Scripts\python.exe phase_reproduction/solvus_cage2304/analysis/direct/run.py --mode scout
.\blind_pilot\.venv-local\Scripts\python.exe phase_reproduction/solvus_cage2304/analysis/direct/run.py --mode final --require-all
.\blind_pilot\.venv-local\Scripts\python.exe phase_reproduction/solvus_cage2304/analysis/direct/field_control.py
.\blind_pilot\.venv-local\Scripts\python.exe phase_reproduction/solvus_cage2304/analysis/direct/export_tables.py
~~~

Добавление `--watch` повторяет локальную проверку до завершения. `scout_summary.csv` относится к уже загруженным полям каждой изотермы. `final_summary.csv` использует полные проверенные манифесты. В `direct_temperature_zeros.json` хранятся прямая интерполяция по соседним значениям \(S_\max\), монотонная оценка и доли повторов с температурной скобкой. В `matched_cage_effects.json` разности определены как результат при границе 0,35 минус результат при границе 0,40. Они охватывают одинаковые фактические поля и составы контактов в каждой клетке, когда обе выборки допускают корень. Величина ограничения безразмерна; объёмы из траекторий имеют единицы Å³/атом.

Проверка алгоритма на архивном N2304/1245 воспроизводит прежние фиксированные разделители 0,42, 0,47 и 0,50 с расхождением менее \(10^{-12}\) по \(S\). Для двух ветвей 1225 К, N768 расхождения в полях и составах составили менее \(3\times10^{-15}\). Эти контрольные изотермы не входят в новую выборку.
