# Влияние ограничения смещений в ячейке из 2304 атомов

Обработана 71 серия при 12 сочетаниях температуры и безразмерной границы смещений. Для каждой изотермы рассчитана самостоятельная свободная энергия по зонтикам порядка. При 1243 К совместный набор для \(W_{\max}=0{,}35\) содержит 176 траекторий и 193 600 производственных записей. Для 0,40, включая независимый длинный повтор, — 160 траекторий и 209 600 записей. Основной фиксированный разделитель бассейнов составляет \(Q=0{,}37\).

У обоих ограничений обе ветви оставались внутри сетки во всех 64 блочных повторениях. Ширины у первой и последней половин траекторий при границе 0,40 составляют +0,277/+0,275 и −0,240/−0,228 п.п. У 0,35 получено +1,297/+1,321 и −0,777/−0,744 п.п. При повышении разделителя от 0,32 до 0,50 Ti-богатая ширина меняется от +1,312 до +1,299 п.п. для 0,35 и от +0,287 до +0,247 для 0,40. На Al-богатой стороне абсолютная ширина меняется с 0,758 до 0,750 и с 0,241 до 0,213 соответственно.

При **одинаковых** 1243 К и \(\mu=3{,}545\) эВ сужение ограничения уменьшает относительную свободную энергию сектора высокого порядка на 0,388 [0,366; 0,411] мэВ/атом. Этот результат использует независимые распределения для двух ограничений и конечносистемные статистические веса с учётом четырёх вариантов D0₁₉. При \(Q=0{,}47\) изменение составляет 0,368 [0,347; 0,389] мэВ/атом. Для тесного ограничения в центре упорядоченной области малый пик низкого порядка лежит высоко по свободной энергии. Заменять этим центральным полем поля сосуществования на краях области нельзя.

## Температура замыкания

Ноль максимума логарифма отношения фазовых весов получен прямой интерполяцией независимых изотерм. При допустимой монотонности центральные оценки равны **1262,72 К** [1260,79; 1264,08] для 0,35 и **1243,49 К** [1243,14; 1243,92] для 0,40. Разность составляет **+19,23 К** [17,32; 20,60]. Интервалы учитывают статистику траекторий, даны при существовании температурной скобки и относятся к ячейке из 2304 атомов. Такая скобка присутствует при обоих ограничениях в 99,2% независимых сочетаний блочных выборок. Простая интерполяция исходных центральных значений даёт 1262,72 и 1243,45 К. В вершине получены 27,260 [27,187; 27,310] и 27,203 [27,169; 27,247] ат.% Al соответственно. Два ограничения дают разные условные статистические ансамбли; расчёт при одном размере сам по себе не задаёт предела без пространственного ограничения.

## Независимость и разрешение

Семь исходных полей для 0,40 при 1243 К дают максимальный логарифм отношения весов +0,702 [0,255; 1,104]. В независимой длинной трёхполевой сетке с новыми начальными состояниями получено +0,193 [−0,225; 0,583]; в 35 из 64 повторов оба контакта находятся в её более узком диапазоне. При одинаковом прямо измеренном поле 3,545 эВ разность между наборами составляет −0,510 [−1,078; 0,121]. После объединения получено +0,494 [0,092; 0,772], первая и последняя половины дают +0,50 и +0,49.

В отдельном анализе каждого химического поля Ti-богатая скобка при 0,35 имеет устойчивые противоположные знаки на обоих концах. Для Al-богатого контакта точечные знаки различны, а интервал на правом краю включает ноль. При 0,40 отдельные соседние полевые группы статистически слабее объединённой оценки и сами по себе не подтверждают обе скобки. Раздельные результаты, проверка с изъятием химического поля и интервалы доступны в `independent_brackets.json` и `leaveout_*.json`.

При исключении всех траекторий любого одного поля максимум логарифма отношения весов остаётся положительным для обеих стенок: 8,875–9,135 при 0,35 и 0,389–0,571 при 0,40. Удаление каждого из девяти внутренних полей для 0,35 оставляет обе ветви, с ширинами от +1,300 до +1,350 и от −0,762 до −0,738 п.п. При удалении каждого из семи внутренних полей для 0,40 соответствующие диапазоны составляют +0,243…+0,299 и −0,249…−0,211 п.п. Удаление края сужает сам интервал, на котором разрешён поиск корня.

В центре при менее тесном ограничении несмещённые цепочки из упорядоченного и случайного стартов сохранили \(Q=0{,}788/0{,}109\) при составах 27,208/27,185 ат.% Al. Между ядрами двух бассейнов за производственную часть они не перешли. При 0,35 оба старта дали упорядоченное состояние \(Q=0{,}818/0{,}836\). Несмещённые пары покрывают 3,510–3,580 эВ при обоих ограничениях. Для двух более далёких контактов при 0,35 физическую опору обеспечили расширенные зонтичные поля.
