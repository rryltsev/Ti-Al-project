# Вершина сольвуса Ti–Al на 2304 атомах при двух ограничениях смещений

Эта серия продолжает [расчёт при пяти размерах](../solvus_closure/README.md). В ячейке ГПУ \(12\times12\times8\) на том же MTP Qi меняется безразмерное ограничение смещений \(W<0{,}35\) или \(W<0{,}40\). Температуры основной серии составляют 1242, 1243, 1244 и 1245 К. Давление равно нулю, объём и \(c/a\) могут изменяться независимо. Отношение химических весов сравнивается после поправки на четыре трансляционных варианта D0₁₉.

**Сужение ограничения с 0,40 до 0,35 повышает температуру замыкания примерно на 18–19 К.** По прямым изотермам температура составляет 1243,49 К при пределе 0,40 и 1262,72 К при пределе 0,35. Их разность +19,23 К имеет условный блочный интервал 17,32–20,60 К. При обоих ограничениях вершина находится около 27,2 ат.% Al. Эти значения относятся к ячейке из 2304 атомов. В полной изотерме 1243 К оба корня для каждой стенки находятся внутри исследованной сетки в 64 из 64 блочных выборок. Оценки в отдельных химических полях имеют больший разброс. Три дополнительных длинных ряда при широкой стенке охватывают 3,530–3,560 эВ и воспроизводят обе границы в 35 из 64 выборок на собственной сетке. [Координаты и интервалы ширин](contacts_1243.csv) · [Прямые изотермы](analysis/direct/final_summary.csv).

При 1243 К в исходную сетку вошли химические поля 3,510, 3,522, 3,533, 3,545, 3,557, 3,568 и 3,580 эВ на замену Ti на Al. Для каждого поля рассчитаны 14 центров зонтика по параметру порядка и два повторных старта. Дополнительные несмещённые траектории с упорядоченного и случайного старта служат для проверки смешивания. Прежние оценки полей контактов при широкой стенке равны 3,53046 и 3,55728 эВ.

Для выбора дополнительных окон использованы первые 275 производственных шагов в двенадцати цепочках при 1242 К, \(W<0{,}35\), \(\mu=3{,}510\) эВ. Даже в этом поле логарифм отношения фазовых весов на один вариант оказался положительным, около +6. Для узкой стенки при 1243 К добавлены поля 3,458, 3,482, 3,600 и 3,624 эВ и назначены прямые изотермы 1254 и 1262 К около вершины. Префиксы служат для выбора параметров. В окончательные оценки каждая полная траектория входит один раз. [Оценка для расширения сетки](analysis/scout_cg3542a.json).

## Независимость расчётов для двух стенок

При старой изотерме 1245 К на 2304 атомах ни один из 38 400 производственных кадров с широкой стенкой не прошёл отбор \(W<0{,}35\). Это исключает прямое вычисление разности свободных энергий стенок простым отбором сохранённых конфигураций. Для каждой стенки своя выборка, абсолютная нормировка между ними для сопоставления температур фазового перехода не требуется. Смена стенки также меняет порог геометрической защиты ячейки. Роль этого условия проверяется отдельно по записям объёма и \(c/a\). [Проверка перекрытия](analysis/wall_screen.json) · [Контроль прежних геометрий](analysis/geometry_history.json).

## Воспроизведение

Подтверждено завершение 71 задания с кодом 0. Получены и проверены 944 цепочки, 998 400 производственных записей и 536 000 записей прогрева. Для скобки температур добавлены 1239 К при широкой стенке и 1254, 1262, 1269 К при узкой. Проверка всех записанных состояний и допустимых промежуточных проб показала положительный запас до геометрической защиты ячейки в обеих сериях. [Аудит UMT](atomistic/provenance.json) · [Проверка геометрии](analysis/geometry_new.json).

В каталоге [atomistic/series](atomistic/series) лежат манифесты. Задания выполняются на `u3129`, в `/home6/u3129/tial-cage2304-20261126`. Прямая изотерма объединяет положительные зонтики при одной температуре. В объединённом MBAR близких температур приведённый потенциал каждого окна вычисляется по сохранённой полной энергии MTP, числу атомов Al и смещению энергии зонтиком. Вершина соответствует одновременно нулю максимума логарифма отношения весов в расчёте на один вариант и стационарности этого отношения по полю. Проверки включают контакты внутри прямой сетки, наличие двух мод порядка, эффективную статистику, чувствительность к разделителю и блочный разброс.

Из корня проекта в PowerShell прямые результаты и независимые по стенкам вершины основной сетки можно получить командами

```powershell
$py = 'blind_pilot/.venv-local/Scripts/python.exe'
$s = 'phase_reproduction/solvus_cage2304'
$env:OPENBLAS_NUM_THREADS = '1'
& $py "$s/analysis/direct/run.py" --mode final --require-all
& $py "$s/analysis/direct/export_tables.py"
& $py "$s/finish_thermal.py"
& $py "$s/summarize_cages.py"
```

Для результатов локального температурного переноса в файлах отмечается, находится ли найденная вершина внутри диапазона исходных температур. Эффективная статистика и поля контактов нужны также при интерпретации корней, лежащих внутри температурной сетки. [Протокол и результаты прямых изотерм](analysis/direct/).
