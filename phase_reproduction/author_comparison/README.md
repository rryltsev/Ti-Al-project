# Сопоставление исходных данных C46 с независимым расчётом Ti–Al

**При одинаковых входных данных наш код воспроизводит авторское кластерное разложение и границы α / α₂. Основной источник расхождения прежних диаграмм — состав обучающей выборки.** Комплект C46 относится к рукописи v16. Проверены SHA-256 всех 124 файлов из манифеста и совпадение контрольной суммы исходного MTP Qi с использованным на UMT. В комплекте есть координаты до и после релаксации при опорном объёме, матрица корреляций, статические и колебательные энергетические данные, маски, ECI, исходники и сохранённые средние по окнам Монте-Карло. [Авторский комплект](../author_package/START_HERE.md)

## Цепочка воспроизведения

| Проверка на одних входах | Что получено |
|---|---|
| Геометрия → корреляции | Наш код непосредственно по координатам воспроизвёл все 920 значений X (46 × 20). Максимальное расхождение 5,34 × 10⁻¹⁴. |
| Энергии → ECI | Воспроизведены 20 ECI на 9 объёмах при 89 температурах 0–2200 K. Максимальная разность для полного ECI равна 2,84 × 10⁻¹⁴ эВ/кластер. |
| Статическая проверка при опорном объёме | Получены авторские RMSE 2,648 мэВ/атом на семи контролях и 5,117 мэВ/атом при поочерёдном исключении обучающих структур. Пять из семи контролей участвовали в выборе базиса. |
| ECI → границы среднего поля | При авторской интерполяции объёма совпали все 139 опубликованных пар сеточных контактов на 147 сечениях. В остальных восьми сечениях оба расчёта не разрешают двух контактов. Наибольшее расхождение шести уточнённых составов при 1000 K — 2,61 × 10⁻⁸ ат.% Al. |
| Средние Монте-Карло → бинодаль | На 970 авторских окнах совпали статусы всех 45 изотерм. Для 26 разрешённых изотерм максимальное расхождение двух обработчиков — 0,00245 ат.% Al. Обратная проверка на 1290 наших окнах тоже дала одинаковые статусы всех 49 изотерм. |

Полный пересчёт подгонки использует сохранённые MTP-энергии и фононные свободные энергии. Независимая проверка самих MTP- и фононных расчётов возможна на пересечении выборок. Проверка MC на одинаковых входах начинается со средних по окнам. Покадровые авторские траектории, индивидуальные фононные силы и частоты в этом комплекте не приложены. ## Чем различаются выборки

Из 46 авторских декораций **восемь** совпадают с нашим окончательным набором с учётом симметрии и периодичности. **38** присутствовали в нашем пуле кандидатов до отбора. Среди восьми общих структур семь входили в обе обучающие выборки, одна была у нас контрольной и у авторов обучающей. Матрицы обучения обеих моделей имеют ранг 20. В каждой первоначально по 39 обучающих и 7 контрольных ячеек.

На восьми эквивалентных декорациях при опорном объёме RMS разности прямых статических энергий MTP составляет **0,00156 мэВ/атом**, для колебательной свободной энергии при 1000 K — **0,00104 мэВ/атом**. Проверены также 72 общие точки «ячейка–объём» и 3528 значений колебательной энергии на общей температурной сетке. При повторной подгонке замена меток одной группы метками другой на общем подмножестве смещает правую границу MFA меньше чем на **0,00030 п.п.** [Общие ячейки и прямые метки](cells/shared_direct_labels.csv) · [Подмена меток на общей части](eci/replace_shared_labels.csv)

Во всём диапазоне объёмов устойчивы 409 из 414 точек у авторов и 396 из 414 у нас. При опорном объёме у авторов устойчивы все 39 обучающих структур, у нас — 37. Две исключённые у нас структуры отсутствуют в C46. Наша статическая правая граница при переходе с 39 на 37 ячеек перемещается с 21,506 до 22,593 ат.% Al. Это **1,088 п.п.** из расхождения **1,795 п.п.** с точными авторскими коэффициентами. На непрерывном пути замены весов одной обучающей выборки другой наибольший положительный вклад у нашей `train_34` (Ti₈Al₄, 12 атомов): +1,416 п.п. в статике, +1,527 п.п. в HA. На этом пути несколько других ячеек действуют в обратную сторону. Подсчёт по весам и проверка фононной маски — два разных сравнения, их вклады складывать нельзя. [Атрибуция по обучающим структурам](eci/training_change_path.csv)

Близкая ошибка по энергиям отдельных структур сочетается с заметной разницей производных свободной энергии по составу. Например, на двух отложенных авторских ячейках с 22 Al на 64 узлах ошибка полной HA-энергии при 1000 K равна 1,031 мэВ/атом для C46 и 1,047 мэВ/атом для нашей модели. [Перекрёстная проверка обоих наборов](eci/cross_validation.csv)

## Правая граница при 1000 K

Все числа — ат.% Al. Для MFA обе модели сравниваются с авторской интерполяцией объёма. Для MC в таблице применены один авторский обработчик и размер системы 5120 узлов к двум ранее рассчитанным сериям.

| Метод | C46, α / α₂ | Наша выборка, α / α₂ | Сдвиг α₂, п.п. |
|---|---:|---:|---:|
| Статика, MFA | 6,159 / 20,799 | 6,758 / 22,593 | +1,795 |
| HA, MFA | 8,926 / 19,421 | 9,653 / 21,079 | +1,658 |
| QHA, MFA | 8,789 / 21,308 | 9,431 / 22,413 | +1,106 |
| Статика, MC | 11,447 / 20,472 | 11,120 / 22,290 | +1,818 |
| HA, MC | 15,281 / 20,612 | 15,173 / 21,656 | +1,043 |
| QHA, MC | 14,958 / 21,958 | 14,764 / 22,707 | +0,748 |

В среднем поле для прямого перехода от точных C46 к нашим ECI вклады `t334` в правую границу составляют **+1,260 / +1,349 / +0,918 п.п.** для статики, HA и QHA. У `t123` получены **+1,008 / +0,838 / +0,709 п.п.** В QHA здесь меняется полная зависимость каждого из 20 коэффициентов от объёма, в том числе постоянного и одноузельного. При опорном объёме статический `t334` равен −0,72648 мэВ/кластер у авторов и −2,46304 у нас, а `t123` — +1,56975 и +2,03684 соответственно. Ранжирование по этим двум тройкам из прежней реконструкции по таблице S1 и рисунку 2 сохранилось.

В QHA одноузельный вклад из-за зависимости от объёма компенсирует **−0,410 п.п.**, постоянный даёт **+0,122 п.п.** При разбиении разности всех ECI на сдвиг уровня в опорном объёме и изменение формы J(V) получены соответственно **+1,163** и **−0,057 п.п.** Вклады получены интегрированием чувствительностей вдоль прямого пути в пространстве коэффициентов. Для дополнительной проверки были заменены обе функции `t334(V)` и `t123(V)` одновременно в авторской модели. При такой конечной замене правая граница QHA переходит с 21,308 до 22,813 ат.% Al. Атрибуция по орбитам относится к MFA. Строки MC в таблице характеризуют разность между полными гамильтонианами. ## Различия реализаций

- В C46 матрица X и экспорт геометрии заданы в формате ATAT. Сохранённый авторский скрипт подгоняет на этой матрице статическую энергию и полную гармоническую свободную энергию методом наименьших квадратов NumPy. Наш код подгоняет статическую и колебательную части раздельно с общей маской. Линейность подгонки даёт одинаковую сумму на одинаковых данных. В нашей независимой серии эта же регрессия ранее была проверена нативным ATAT `lsfit`.
- Имена `t222_capped` и `t222_uncapped` соответствуют нашим `t222_1` и `t222_2`. Авторский `eci.out` для MC-драйвера хранит физический J. Наш экспорт для `corrdump -eci`, возвращающего эВ/атом, содержит J/2 в собственном порядке орбит. У функций предсказания энергии одинаковая нормировка с учётом кратности на атом. [Таблица геометрического соответствия](cells/orbit_mapping.csv)
- Для кубического сплайна по объёму авторы использовали граничное условие `not-a-knot`; в прежнем независимом расчёте использован натуральный сплайн. На точных авторских ECI это меняет правую границу MFA при 1000 K с 21,308 до 21,284 ат.% Al. Оба режима теперь доступны в обычной команде нашего MFA. На полном диапазоне при смене сплайна восемь из 43 разрешённых сечений QHA C46 смещаются на один шаг сетки (0,05 п.п.), остальные совпадают. [Данные по температурам](thermo/mfa_comparison_grid.csv)
- В авторском C++-драйвере химический потенциал сопряжён со спином. Его входной `mu_spin` соответствует половине нашего входного потенциала на обмен Ti→Al. При этом оба кода дают один и тот же химический потенциал по среднему составу окна и одинаковую смену квадратичного ограничения при перевороте спина. Оба используют симметричный объёмный ход при нулевом давлении; полуразмах шага у авторов 0,035 Å³/атом, у нас 0,045. Авторская реализация также сохраняет величину с температурной производной ECI. Наше поле `Heff_eV_atom` содержит эффективную энергию при заданной температуре.
- Для построения касательной оба кода интегрируют PCHIP-интерполяцию химического потенциала. Авторский затем уточняет корень для самого широкого участка выпуклой оболочки. Наш исходный обработчик сохраняет все внутренние участки шириной более 0,5 п.п. и оценивает состав на мелкой сетке. В одном из наших 49 сечений имеются две опорные касательные, поэтому при сравнении обработчиков сопоставлялся самый широкий участок. Для физической классификации нескольких ветвей мы отдельно использовали параметр порядка.

## Как повторить сравнение

Из корня рабочего проекта при наличии Python, NumPy и SciPy можно рассчитать все шесть MFA-составов при 1000 K из заново подогнанных авторских коэффициентов:

```bash
python phase_reproduction/thermo/mfa.py phase_reproduction/author_comparison/eci/author_refit_grid.npz replay_1000K --temperatures 1000 --models static HA QHA --volume-spline not-a-knot
```

Для независимой проверки исходных окон передайте путь к корню авторского комплекта программе [compare_mc.py](compare_mc.py). Для проверки вкладов с полной сеткой C46 выполните [qha_attribution.py](qha_attribution.py).
