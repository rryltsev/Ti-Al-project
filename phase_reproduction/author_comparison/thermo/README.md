# Проверка MFA на авторских ECI C46

Один и тот же код четырёхподрешёточного MFA пересчитал бинодали сначала на точных авторских ECI, затем на ECI нашей независимой подгонки. Использованы сетки 600–1800 K через 25 K и 0–35 ат.% Al через 0,05 ат.%. При 1000 K две точки общей касательной дополнительно уточнены непрерывным решением условий равновесия. Для QHA объёмы двух фаз релаксированы независимо при нулевом давлении. Константа и одноузельный член включены со своей полной зависимостью от объёма.

| Приближение | Точные ECI C46, α / α₂ при 1000 K | Наша подгонка, тот же код | Наша α₂ минус C46, п.п. |
|---|---:|---:|---:|
| Статика | 6,15929 / 20,79866 | 6,75816 / 22,59322 | +1,79456 |
| HA | 8,92571 / 19,42095 | 9,65308 / 21,07908 | +1,65813 |
| QHA, авторский тип сплайна | 8,78865 / 21,30774 | 9,43135 / 22,41329 | +1,10555 |

Все шесть точных координат при 1000 K совпали с авторским файлом `C46_MFA_tangent_refinement_1000K.json` с максимальным отклонением 2,61×10⁻⁸ ат.% Al. При использовании авторских ECI получили все 139 опубликованных пар сеточных контактов, по 49 для статики, 47 для HA и 43 для QHA, без расхождения даже на одну точку сетки. В остальных восьми сечениях также отсутствуют два внутренних контакта шириной не менее 0,50 ат.% Al. Вывод относится к ограничению области соста́вов и разрешению сетки.

На обеих сетках объёма используется кубическая интерполяция. Авторский генератор таблиц задаёт стандартное граничное условие SciPy `not-a-knot`, наш прежний код применял `natural`. При 1000 K на авторских ECI замена `not-a-knot` на `natural` меняет границы на +0,00303 / −0,02387 п.п. На наших ECI те же изменения составляют +0,00518 / −0,01554 п.п. На всей сетке изменилась одна координата максимум на 0,05 п.п. в восьми из 43 разрешённых сечений авторского набора и в десяти из 42 наших. Число разрешённых сечений сохранилось. В QHA при 1000 K равновесные объёмы авторских фаз равны 17,60605 / 17,26691 Å³/атом.

Сетка ECI авторского набора содержит 89 температур и хранит производные по температуре для интерполяции Эрмита между узлами. Все сравниваемые температуры присутствуют на обеих сетках. При повторном анализе MC следует учитывать, что исходный драйвер авторов пробует изменение объёма размером до 0,035 Å³/атом один раз на проход, наш драйвер использовал 0,045 Å³/атом. Оба используют равномерное симметричное предложение и метрополисовское правило при нулевом давлении. Это различие способно влиять на перемешивание объёма.

## Связь с прежним разбором ECI

При замене точных авторских ECI на наши вдоль прямой в пространстве коэффициентов суммы вкладов в сдвиг α₂ составляют +1,795 п.п. в статике и +1,658 п.п. в HA. Для t334 вклады составляют **+1,260 и +1,349 п.п.**, для t123 — **+1,008 и +0,838 п.п.** соответственно. Семь пар суммарно дают −0,395 и −0,494 п.п. Прежняя реконструкция для t334 давала +1,275 и +1,380, для t123 — +1,020 и +0,850. Выбор двух ведущих троек в MFA устойчив к замене рисунка и печатной таблицы машинными значениями. Для каждой из 18 орбит также проверены отдельные прямые и обратные конечные замены. Все числа в этом разделе относятся к правой границе α₂ в MFA при опорном объёме.

## Воспроизведение

Для вычислений нужны Python, NumPy и SciPy. Для вывода рисунка добавьте Matplotlib. Под `PACKAGE` подразумевается каталог, содержащий `ECI_TiAl.csv` и подкаталоги `models` и `phase_check`.

```sh
python phase_reproduction/author_comparison/thermo/compare_mfa.py PACKAGE --workers 4
python phase_reproduction/author_comparison/thermo/compare_mfa.py PACKAGE --all-temperatures --workers 4
python phase_reproduction/author_comparison/thermo/summary.py
```

Первый запуск пишет уточнённые точки и атрибуцию ECI. Второй сохраняет на диске 392 температурных сечения, включая обе интерполяции QHA и оба набора ECI. В свободной энергии непосредственно используются 20 исходных ECI, собственные орбитные веса, минимизация по заполнению подрешёток и нижняя выпуклая оболочка. Перенос коэффициентов сверяется с именами, порядком и короткой таблицей авторов.
