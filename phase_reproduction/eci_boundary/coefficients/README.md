# Сопоставление эффективных взаимодействий Ti–Al при 1000 K

При опорном объёме 17.28832985 Å³/атом у новой подгонки и опубликованной модели совпадают знаки **всех семи парных и одиннадцати тройных полных взаимодействий HA**. Среднеквадратическое различие по этим 18 коэффициентам равно 1.320 мэВ/кластер. Для статики на общей фононной маске оно составляет 1.673 мэВ/кластер, для колебательной поправки — 0.525 мэВ/кластер. Энергетическое действие разности параметров зависит от корреляций химической конфигурации.

## Что известно о модели статьи

Таблица S1 даёт 20 округлённых статических взаимодействий, включая постоянный и одноузельный члены. Для p1 запись 0.049 эВ имеет половину последнего печатного разряда 0.5 мэВ, для t247 запись −0.0000181 эВ — 0.00005 мэВ. Рис. 2 содержит красные столбцы гармонических поправок для семи пар и одиннадцати троек. Их оцифровали по исходному растру 2100×840. Масштаб пикселя составляет 0.14545 мэВ/кластер для пар и 0.03298 для троек. При проверке калибровки на голубых статических столбцах все 18 высот попадают в интервал округления S1, расширенный на один пиксель. Половина печатного разряда и размер пикселя характеризуют точность представления. Для статистической погрешности подгонки потребовались бы данные выборки. [Статья, рис. 2](<../../manuscript_v16/TiAl_MTP_v16_статья.docx>). [Приложение, S1 и S2](<../../manuscript_v16/TiAl_MTP_v16_дополнительные_материалы.docx>).

В [сопоставлении 20 орбит](coefficients_1000K_vref.csv) пустые поля у авторских колебательных и полных коэффициентов для постоянного и одноузельного членов означают отсутствие наблюдения. При одном объёме эти члены меняют общий энергетический ноль и наклон по составу. В разностях между состояниями одного состава они сокращаются. При оптимизации объёма их объёмная зависимость входит в давление, поэтому восстановить авторскую QHA из этих столбцов нельзя.

В предоставленной папке PD и её ZIP проверены перечень файлов, состав обоих DOCX и листы Excel. В таблице фазовой диаграммы три листа — «MC», «Эксперимент» и «Линии». В архиве от 16 октября лежат точки и оцифровка диаграммы, оформление рисунка и две статьи-источника. В DOCX отсутствуют вложенные рабочие книги и исходные таблицы диаграмм. В S1 есть ссылка на машинный комплект, однако в переданных файлах полных авторских массивов J(V,T) нет. S2 содержит частичные физические проверки, в том числе понижение свободной энергии D0₁₉ от релаксации объёма на 2.16 мэВ/атом при 600 K и изменение разности объёмных поправок случайной и D0₁₉-конфигураций на +0.105 мэВ/атом при 1000 K. По таким скалярам сетку ECI не восстановить. Октябрьский TiAl_full_pipeline.pdf описывает более ранний базис W с четвёрками и переносом HA64 на одно взаимодействие. ## Влияние двух исключённых структур

В исходной статической подгонке использованы все 39 обучающих меток. На тех же декорациях фононы train_26 и train_30 при опорном объёме имеют внутренние мнимые частоты −1.3155 и −0.1786 ТГц. На оставшихся 37 обучающих строках одновременно подогнаны статика и Fvib. Обе модели имеют ранг 20, одинаковые семь контрольных ячеек и одинаковый вес обучающей структуры. В S2 авторская выборка при этом объёме имеет 39 устойчивых обучающих ячеек.

При переходе 39→37 среднеквадратическое изменение 18 нелинейных J составило **0.597 мэВ/кластер**. Среди пар наиболее заметно изменились p2 (+1.265), p1 (+1.105) и p3 (−0.990 мэВ/кластер). Среди троек наибольший сдвиг имеет t136 (−0.687 мэВ/кластер). В таблице отдельно даны изменения при исключении каждой из двух структур. Это две повторные подгонки, их эффекты в общем случае не складываются. На семи контролях RMSE прямой статической энергии составляет 2.320 мэВ/атом для 39 строк и 2.483 для 37. RMS изменения самих семи предсказаний — 2.286 мэВ/атом. Статика из S1 на этих же семи **новых** конфигурациях даёт 4.758 мэВ/атом. Для авторских семи контролей статья сообщает 2.65 мэВ/атом.

Наибольшие различия полных HA-коэффициентов (новая модель минус реконструкция статьи) имеют t222 типа 2 (+3.424), p1 (+2.656) и p6 (−1.697 мэВ/кластер). Для статики разный знак получен у t112, у колебательной поправки — у t136 и t226. Суммы статики с поправкой для этих трёх орбит сохраняют общий знак. Для двух типов 222 использовано сопоставление по геометрии. Нативный ATAT выводит их в противоположном порядке относительно S1.

Для t222 типа 2 расхождение именно статических коэффициентов составляет +3.128 мэВ/кластер, тогда как исключение двух структур сдвигает наше значение лишь на −0.051 мэВ/кластер. Для p1 роль маски заметнее — +1.105 при статическом расхождении +3.787 мэВ/кластер. Это разделяет измеримый вклад собственной маски и различие двух моделей. Разложить остаток между точными декорациями авторской выборки, исходными фононными метками и деталями их подготовки невозможно без авторских строк и меток. При одном и том же MTP разные наборы корреляций и меток в общем случае дают разные коэффициенты усечённой подгонки.

## Какие химические состояния получают преимущество

В спиновом базисе Ti=−1 и Al=+1 положительное J пары понижает её вклад для разноимённых соседей. В обеих моделях у пары p1 между соседними базальными слоями и у пары p2 в одном слое J положителен, а Fvib уменьшает его. В HA при 1000 K значения p1 составляют 43.570 и 46.226 мэВ/кластер (статья и новый расчёт), p2 — 32.461 и 32.927. Тройки также входят в энергию замены атома.

| Проба при опорном объёме и 1000 K | Модель статьи | Новая модель |
|---|---:|---:|
| Независимое случайное заполнение при 25% Al минус идеальный D0₁₉, мэВ/атом | 72.628 | 71.311 |
| Цена обмена Al↔Ti между соседями p1 в идеальном D0₁₉, эВ/пару | 0.616 | 0.625 |
| То же для p2, эВ/пару | 0.718 | 0.721 |
| Обмен Al↔Ti в D0₁₉ за пределами седьмой оболочки, эВ/пару | 0.810 | 0.813 |
| Две Al-примеси в α-Ti в p1 относительно разнесённых, эВ/пару | +0.146 | +0.128 |
| То же для p2, эВ/пару | +0.077 | +0.073 |

Первая строка использует математическое ожидание кластерных произведений при независимых занятиях и точные корреляции идеально упорядоченного кристалла. Обе модели предпочитают D0₁₉. Статическая разность равна +91.006 и +89.245 мэВ/атом, колебательные поправки равны −18.377 и −17.935 мэВ/атом. Для конкретной пары при 22 Al на 64 узлах доступны прямые метки MTP. Полная разность «случайная минус D0₁₉-подобная» равна **+43.070 мэВ/атом** (статика +51.519, колебания −8.450). На этих же двух контрольных декорациях коэффициенты статьи дают +45.750, новая CE — +46.700 мэВ/атом. Эта пара была отложена до подгонки.

Для антиструктурных проб использована периодическая ячейка 8×8×6 с 768 узлами. Один обмен сохраняет стехиометрию. Для каждой ближней оболочки испробованы все шесть соседей. Для примесей α-Ti энергия состояния с теми же двумя Al за пределами радиуса CE вычитается из энергии ближней пары. Разница между моделями наиболее выражена в штрафе за Al–Al в первой оболочке разбавленного α-Ti — около 18 мэВ/пару. Величины относятся к эффективному гамильтониану заданных декораций. Для определения концентраций дефектов и сдвига бинодали требуется конфигурационная выборка. [Вклады отдельных орбит](order_contributions.csv). [Энергии дефектных проб](defect_probes.csv).

Скрипт [compare.py](compare.py) читает S1 непосредственно из DOCX, проверяет хеши источников оцифровки, повторяет статическую подгонку с обоими исключениями и записывает таблицы. Для воспроизведения требуются NumPy и путь к папке PD. [Численные итоги](summary.json).

## Воздействие маски на контакты MFA при 1000 K

Общая касательная рассчитана заново для каждого набора коэффициентов. Для каждого решения проверено, что касательная не пересекает гомогенную поверхность на контрольной сетке состава и порядка.

| Число статических меток | Исключены | Статика α / α₂, ат.% Al | С добавлением одной и той же Fvib(37), α / α₂, ат.% Al |
|---:|---|---:|---:|
| 39 | — | 6.805 / 21.506 | 9.488 / 19.552 |
| 38 | train_26 | 6.780 / 22.023 | 9.542 / 20.225 |
| 38 | train_30 | 6.807 / 21.742 | 9.539 / 19.863 |
| 37 | обе | 6.758 / 22.593 | 9.653 / 21.079 |

Для статики исключение обеих ячеек увеличивает состав α₂ при сосуществовании на 1.088 процентного пункта. Исключения по одному дают +0.517 и +0.237 п.п. Совместное действие сверх их суммы равно +0.334 п.п. При поровну разделённом совместном действии вклады составляют +0.684 и +0.404 п.п. для train_26 и train_30. На Ti-богатой ветви общий сдвиг составляет −0.047 п.п.

В последнем столбце неизменная колебательная часть подогнана на 37 устойчивых метках. Первая и две промежуточные строки — искусственные сочетания, которые изолируют влияние **статической** подгонки. Конечная строка имеет общую маску. Между первой и последней строками α₂ сдвигается на +1.527 п.п., из них +0.673 и +0.311 п.п. получаются при отдельных исключениях, +0.543 п.п. составляет совместная часть. При симметричном распределении это +0.944 и +0.582 п.п. Для α суммарный сдвиг равен +0.165 п.п. [Контакты и заполнения подрешёток](mfa_contact_stress_1000K.csv). ## Точность восстановления статьи по таблице и рисунку

Каждому взаимодействию задано отклонение на половину последнего разряда S1. Для гармонических поправок дополнительно задано отклонение на один пиксель соответствующей панели. Два угла прямоугольной области допусков выбирались по знакам производных состава α₂ по каждому J при номинальном решении. В этих двух точках заново решены нелинейные условия общей касательной. Остальные углы не перебирались, распределение ошибок оцифровки не вводилось. Эти расчёты характеризуют направленную чувствительность α₂ без присвоения уровней доверия. Они не дают экстремумов ветви α.

| Возмущение восстановленной статьи | Меньший и больший сдвиги α₂, п.п. |
|---|---:|
| Статика, только печатное округление S1 | −0.183 / +0.174 |
| HA, только печатное округление S1 | −0.200 / +0.195 |
| HA, только один пиксель для красных столбцов | −0.527 / +0.502 |
| HA, округление S1 и пиксель одновременно | −0.736 / +0.685 |

Номинальная реконструкция даёт α₂ = 20.708 ат.% для статики, 19.219 ат.% для HA. При непосредственно доступной альтернативной оцифровке, где статические коэффициенты берутся из голубых столбцов, получаются 20.795 и 19.264 ат.%. Интервал между двумя проверенными углами HA при совместном возмущении составляет 18.483–19.904 ат.%. В статье приведены 20.80 и 19.42 ат.% соответственно. В новой согласованной подгонке соответствующие составы равны 22.593 и 21.079 ат.%. Полные результаты включают оба контакта и сравнение с линейным предсказанием для α₂.
