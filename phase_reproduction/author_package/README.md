# Ti–Al. Эффективные кластерные взаимодействия для фазового равновесия α/α₂

Роман, в этом комплекте — коэффициенты, с которыми мы строили обе диаграммы в статье: в приближении среднего поля и решёточным методом Монте-Карло. Начать можно с **ECI_Vref_1000K.csv**: это 20 строк при одном объёме. Для расчётов бери **ECI_TiAl.csv**: в нём те же 20 коэффициентов на всей сетке температур и объёмов. Раздел 4 объясняет другой способ получить взаимодействия — последовательно помещать два, три и четыре атома Al в большую ячейку Ti. Файлы с результатами статьи и учебный пример для четвёрки лежат отдельно.

## 1. Как читать таблицу

Строка **ECI_TiAl.csv** задаёт один тип кластера при заданных T и V. В файле 9 объёмов на атом, 89 температур от 0 до 2200 К с шагом 25 К и 20 коэффициентов для каждой пары T, V. Фазовые границы в статье исследовали в более узкой области, 600–1800 К и до 35 ат. % Al. Наличие коэффициентов само по себе не устанавливает сосуществование фаз.

| Поле | Что в нём записано |
|---|---|
| T_K, V_A3_per_atom | Температура в К и объём в Å³/атом. Для статики и гармонического расчёта статьи выбирай опорный объём 17.288329847774033 Å³/атом. |
| index, cluster, order | Индекс от 0 до 19, имя и число узлов в кластере. Сначала постоянный и одноузельный члены, затем 7 пар по координационным сферам и 11 типов троек. |
| multiplicity_per_atom | Число геометрически эквивалентных размещений данного кластера в расчёте на один узел. |
| J_static_eV | Коэффициент разложения статической энергии при данном объёме. |
| delta_J_vib_eV | Разность полного и статического коэффициентов при том же объёме. Описывает вклад колебательной **свободной энергии**, включая энергию нулевых колебаний. |
| J_effective_eV | Полный коэффициент с учётом колебаний. Равен J_static_eV + delta_J_vib_eV. Если берёшь эту колонку, поправка уже включена. |

В коротком файле поправка подписана **delta_J_vibrational_1000K_eV**. Кратности там даны в двух нормировках: на примитивную ячейку из двух узлов и на атом. Все числа в машиночитаемых файлах сохранены с исходной точностью. Геометрия представителей и порядок коэффициентов записаны в **models/geometry.json** и в исходных **lat.in**, **clusters.out**. Две тройки с одинаковым набором расстояний 222, **t222_capped** и **t222_uncapped**, геометрически различны и имеют разные строки.

## 2. Что означает коэффициент и как собрать энергию

Положим sᵢ = −1 для Ti и +1 для Al. Для каждой конфигурации σ и типа кластера k усредняем произведение спинов по всем его эквивалентным размещениям. Получаем корреляцию ρₖ. Если mₖ — кратность на атом, то энергия в расчёте на атом равна

**h(σ) = Σₖ mₖ Jₖ ρₖ(σ).**

Для полной энергии ячейки умножаем результат на число узлов N. Для постоянного члена ρ₀ = 1 и m₀ = 1/2, для одноузельного m₁ = 1 и ρ₁ = 2c_Al − 1. Если же считаешь сумму произведений явным перебором размещений кластера в ячейке, каждое размещение учитывается один раз и множитель кратности уже содержится в этой сумме.

У пары одинаковые атомы дают произведение +1, разные — −1. Поэтому положительный парный J понижает энергию разноимённой пары относительно одноимённой в этом члене гамильтониана. Чтобы сравнить две реальные конфигурации, нужно сложить все члены. Тройка описывает зависимость энергии от совместного заполнения трёх узлов сверх того, что различает выбранный парный базис.

Простейшая проверка — чистый ГПУ-Ti. У него ρ = +1 для любой пары и −1 для любой тройки. При опорном объёме сумма даёт −7,896 эВ/атом для статической модели и −8,272 эВ/атом для полной гармонической модели при 1000 К. Команда `python3 check_eci.py` воспроизводит обе суммы и сверяет весь CSV с исходными массивами модели.

## 3. Как получены ECI для статьи

Мы взяли энергии 46 периодических конфигураций Ti–Al, рассчитанные с одним опубликованным MTP. В номинальную подгоночную выборку вошли 39 структур, семь оставили для контроля энергий. Пять из семи ранее использовались при выборе базиса. Для каждой конфигурации известны атомные заполнения, а значит, и все столбцы Xₖ = mₖρₖ. При каждом объёме решили задачу наименьших квадратов по энергиям **на атом**. Сначала целевой величиной служила статическая энергия MTP, затем — статическая энергия плюс рассчитанная по фононам свободная энергия при данной температуре. При каждом объёме для двух подгонок использовали общую маску устойчивых конфигураций.

Это кластерное разложение в формализме Коннолли–Уильямса. Геометрия и таблицы подготовлены в формате ATAT, а совместная подгонка в этом проекте выполнена сохранённым скриптом. Программа перебирает структуры целиком: в одной структуре одновременно присутствует много пар и троек. Один набор коэффициентов описывает энергии всех включённых структур. Для статьи выбран базис из пар и троек. Модель с четвёрками лучше описывала семь контрольных энергий, но хуже предсказывала энергии при поочерёдном исключении обучающих структур. Это основание выбора базиса, а не оценка вклада четвёрок в бинодаль.

Исходный моментно-тензорный потенциал описан в работе [Qi и соавт., Physical Review Materials 7, 103602 (2023)](https://doi.org/10.1103/PhysRevMaterials.7.103602). Для применения переданных ECI к решёточной модели файл MTP не требуется.

## 4. Как выделить взаимодействия вручную в сверхъячейке Ti

Здесь другой вопрос: сколько энергии добавляет **именно совместное присутствие выбранных примесей**, когда вклады всех меньших групп уже вычтены? Для такого расчёта удобно использовать переменные заполнения nᵢ = 0 для Ti и 1 для Al.

1. Построй большую периодическую ГПУ-сверхъячейку чистого Ti. Выбери узлы A, B, C, D, зафиксируй их координаты и расстояния с учётом периодических границ. Конкретный геометрический пример — три узла одного базального слоя (0,0,0), (1,0,0), (0,1,0) и узел соседнего слоя (1/3,1/3,1/2). Координаты даны в векторах примитивной решётки из lat.in. Перенеси эту группу внутрь сверхъячейки. Нормированная lat.in служит для перечисления соседей; физические параметры ячейки статьи при опорном объёме составляют a = 2,9446 Å и c = 4,6046 Å.
2. Для каждого подмножества S замени на Al только атомы в S. Все остальные узлы содержат Ti. E(S) — **полная энергия всей сверхъячейки** с таким заполнением. E(∅) — энергия чистой сверхъячейки Ti. В пределах одной серии сохрани число узлов, потенциал, объём и условия релаксации. Если проверяешь зависимость от объёма, повтори весь набор при новом объёме.
3. Для пары AB нужны четыре заполнения: ∅, A, B, AB. Для тройки ABC нужны восемь, включая именно её три ребра AB, AC и BC. Для четвёрки ABCD нужны 16: чистая ячейка, четыре одиночные примеси, шесть пар, четыре тройки и полная четвёрка. Симметрично эквивалентный расчёт можно переиспользовать после проверки геометрии. В сумме по подмножествам остаются все вхождения, в том числе повторяющиеся по симметрии.
4. Выдели неприводимые взаимодействия по формулам ниже. Проверь результат повторным, рекурсивным вычитанием всех младших вкладов. Для оценки размера сверхъячейки повтори расчёт в большей ячейке с **той же геометрией кластера** и сравни саму разность W. Периодические копии примесей, а при релаксации и их поля деформации, могут менять результат.

**Пара.** W(AB) = E(AB) − E(A) − E(B) + E(∅).

**Тройка.** W(ABC) = E(ABC) − [E(AB) + E(AC) + E(BC)] + [E(A) + E(B) + E(C)] − E(∅).

**Четвёрка.** W(ABCD) = E(ABCD) − [E(ABC) + E(ABD) + E(ACD) + E(BCD)] + [E(AB) + E(AC) + E(AD) + E(BC) + E(BD) + E(CD)] − [E(A) + E(B) + E(C) + E(D)] + E(∅).

Каждое W выражено в **эВ на указанный кластер** в данной периодической матрице. Делить на N, число соседей или факториал не нужно. Отрицательное W означает дополнительное понижение энергии сверх младших вкладов. Чтобы узнать полное связывание четвёрки относительно четырёх отдельных примесей, используют другую величину: B(ABCD) = E(ABCD) − ΣᵢE(i) + 3E(∅). Она включает пары, тройки и саму четвёрку.

**Численный пример.** В `example/illustrative_cell_energies.csv` перечислены все 16 **учебных** полных энергий. Запусти `python3 example/check_subsets.py`. Получатся W(AB) = +0,10, W(ABC) = −0,03, W(ABCD) = +0,04 эВ/кластер. Полное связывание четвёрки B = +0,52 эВ/кластер. Скрипт проверяет обе формулы извлечения для каждого подмножества. Эти числа придуманы для проверки знаков и счёта групп и не являются результатом для Ti–Al.

**Почему таблицы J и W нельзя сопоставить построчно.** В статье J относится к произведениям спинов sᵢ, а примесное W — к произведениям заполнений nᵢ. Переход sᵢ = 2nᵢ − 1 меняет и младшие коэффициенты. Например, один член W(AB)n_A n_B после подстановки превращается в W(AB)(1 + s_A + s_B + s_A s_B)/4. Тройка даёт также пары, а четвёрка — тройки, пары, одноузельные и постоянный члены. Переводить нужно весь гамильтониан с геометрическими кратностями. Кроме того, две независимые параметризации отвечают разным наборам энергий: одна подогнана по сплавам разных составов, другая определена в пределе отдельных примесей в Ti. Содержательное сравнение — собрать **две полные модели**, посчитать одни и те же конфигурации при одинаковых механических условиях, затем сравнить растворимость или бинодали в одном статистическом методе. Для примесной модели нужны также опорная энергия чистого Ti и одноузельный вклад E(A) − E(∅).

При добавлении фононов в примесный вариант те же разности можно брать по полным F(S,T,V) при общих T и V. Это даёт температурно- и объёмно-зависимые W. Смешение энергий ячеек, независимо отрелаксированных по объёму, с энергиями при общем фиксированном объёме меняет физический смысл разности.

## 5. Как перейти от коэффициентов к фазовой диаграмме

| Вариант | Какие коэффициенты брать |
|---|---|
| Без учёта колебаний | J_static_eV при опорном объёме. |
| Гармоническое приближение (HA) | J_effective_eV при нужной T и опорном объёме. |
| Изотропное квазигармоническое приближение (QHA) | Тот же набор J_effective_eV(T,V), но с переменным общим объёмом при фиксированном c/a и нулевом внешнем давлении. В среднем поле оптимизируем объём, в MC выбираем его наряду с химическими конфигурациями. |

**Среднее поле.** Для упорядочения типа D0₁₉ вводим две вероятности заполнения узла алюминием, q и r, с весами 1/4 и 3/4. Тогда c_Al = (q+3r)/4. При подсчёте каждого кластера спин на узле заменяется на его среднее 2q−1 или 2r−1 согласно подрешётке; для эквивалентных размещений усредняются соответствующие произведения. Добавляем к энергии вклад идеальной конфигурационной энтропии подрешёток и при заданном составе минимизируем свободную энергию по допустимым заполнениям. В QHA минимизируем также по объёму. В результате получаем свободную энергию на атом как функцию состава.

**Решёточный Монте-Карло.** Используем фактические спины конфигурации. При пробной смене Ti ↔ Al пересчитываем изменение суммы по затронутым кластерам. В HA и QHA используем полные J(T,V) уже при выборе конфигураций. Конфигурационная энтропия возникает из статистической выборки. В статье использовался метод с ограничением флуктуаций состава (VC-SGC). В серии расчётов при одной температуре получаем Δμ(c) = μ_Al − μ_Ti и интегрируем по атомной доле Al от опорного состава, что даёт разность свободных энергий на атом. В поставляемом MC-драйвере для этого служит `mu_occ_eV`; входной параметр `mu_spin` имеет другую нормировку и не включает поправку смещающего потенциала окна.

**Сосуществование.** При одной T строим общую опорную касательную к зависимости свободной энергии от состава. Две точки касания дают составы α и α₂. Касательная должна проходить снизу по отношению к конкурирующим состояниям. Ориентир из статьи при 1000 К в HA: α/α₂ = 8,93/19,42 ат. % Al в среднем поле и 15,28/20,61 ат. % Al в решёточном MC. Это равновесие внутри выбранной ГПУ-модели.

## 6. С чего начать в Codex

Распакуй ZIP, открой каталог в Codex и передай ему следующий запрос:

> Прочитай README.md. Запусти python3 check_eci.py и python3 example/check_subsets.py. Покажи, как для чистого Ti получаются статическая и гармоническая энергии при 1000 К и опорном объёме. Затем на примере четвёрки ABCD объясни, почему её полное связывание отличается от собственного четверного взаимодействия. Используй кластерные коэффициенты статьи для первого расчёта и учебные энергии только для второго.

Для самостоятельного повтора **подгонки** нужна среда Python с NumPy и SciPy. Из корня пакета выполни:

```sh
python3 source/reproduce_C46_coefficient_fit.py . > fit_report.json
```

Скрипт повторяет МНК по исходным энергиям на всех объёмах и температурах и проверяет таблицы интерполяции. Для первого теста нужен только NumPy, для учебного примера достаточно стандартной библиотеки Python. Каталог **models/** содержит исходные массивы признаков, энергии, маски и таблицы драйвера. Полные интерполированные коэффициенты для промежуточных T и V вычисляются из qha_ce.dat по алгоритму source/qha_volume_atat.h. Один файл eci.out не заменяет температурно-объёмную таблицу. Для сборки собственного драйвера VC-SGC из **source/** требуется отдельная установка исходников и объектных файлов ATAT. Пакет предназначен для чтения коэффициентов и воспроизведения подгонки; новые траектории MC и новая диаграмма при этих проверках не строятся.
