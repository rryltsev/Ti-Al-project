# Что передать Codex

Комплект к статье «Расчёт равновесия фаз α и α₂ в системе Ti–Al с моментно-тензорным потенциалом: роль химических корреляций и вибрационной энтропии».

**46 — число периодических конфигураций для построения и проверки кластерного разложения.** Опубликованный MTP использован без переобучения. Разные конфигурации могут иметь один состав и различаться расположением Al.

| Этап | Для подгонки | Для контроля | Для чего добавляли |
|---|---:|---:|---|
| Исходные 19 | 14 | 5 | Исходная выборка включает упорядоченные, разбавленные и случайную конфигурации |
| Ещё 21 | 21 | 0 | Устранить линейную зависимость и лучше различать многочастичные взаимодействия при сравнении базисов |
| Ещё 6 по 64 атома | 4 | 2 | По одной случайной и одной D0₁₉-подобной структуре при 17, 20 и 22 атомах Al. Обе структуры с 22 Al оставлены для контроля |
| Всего | 39 | 7 | В окончательном базисе 20 коэффициентов |

Старые пять контрольных конфигураций участвовали в выборе базиса. При отдельном объёме из подгонки исключались конфигурации с неустойчивыми фононами по маске stable. Девять объёмов и 89 температур описывают те же химические конфигурации.

**Где координаты.** В structures/index.csv порядок строк и индексы 0–45 совпадают с X в models/*/volume_temperature_coefficients.npz. Для каждой строки есть исходный parent_POSCAR и relaxed_POSCAR после релаксации с MTP в фиксированной ячейке при опорном объёме. Два исходно переиспользованных расчёта включены в симметрийно эквивалентной ячейке для relaxed_POSCAR, см. equivalent_cell_reused. Для собственного потенциала начинать с parent_POSCAR и повторять релаксацию в тех же механических условиях. В POSCAR встречаются повторные группы элементов, например Ti Al Ti: сохранять принадлежность каждого узла и порядок координат.

**Где ECI.** Полная таблица ECI_TiAl.csv и массивы eci формата float64 в models/static и models/HA_QHA. Модель static даёт статические энергии, HA_QHA — статическую плюс колебательную свободную энергию. Для работы только с исходными численными энергиями и таблицами коэффициентов достаточно NumPy. Для проверки подгонки и фазовых границ нужны NumPy и SciPy.

**Как проверить после распаковки.** Из корня каталога выполнить:

```sh
python3 check_eci.py
python3 source/reproduce_C46_coefficient_fit.py . > fit_report.json
python3 phase_check/check_binodals.py
```

Первый тест сверяет CSV с исходными численными массивами, второй повторяет подгонку. Третий восстанавливает общие касательные по сохранённым средним значениям состава и химического потенциала в окнах MC и сверяет 45 результатов (включая неразрешённые случаи). Это проверка обработки, без повторной генерации траекторий. Для MFA приложены исходные табличные границы и уточнённые контакты при 1000 К.

**Дополнительно для ATAT.** structures/structures.out содержит те же 46 исходных конфигураций в порядке индекса. В каталоге с lat.in и clusters.out из models/static можно посчитать корреляции командой `corrdump -l=lat.in -c -s=/путь/к/structures.out -sig=14 -z=1e-7`. Для сопоставления с X умножить каждый столбец на multiplicity_per_atom из models/geometry.json. При упаковке проверены все 46 × 20 значений, составы, объём родительских ячеек и соответствие статических энергий при опорном объёме массиву для подгонки. В файле manifest.json записаны контрольные суммы файлов.

Для знакомства с физическим смыслом коэффициентов, сравнением с примесными взаимодействиями и переходом к фазовым границам см. README.md.
