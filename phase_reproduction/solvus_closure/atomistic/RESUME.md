# Продолжение расчёта после выключения ПК

Все 36 вычислительных заданий приняты Slurm под пользователем `u3129`. Каждая серия работает в отдельном каталоге `/home6/u3129/tial-closure-20261126/<имя серии>`. В нём сохраняются `job.id`, `slurm-<id>.out`, `windows.csv`, пооконные CSV, финальные конфигурации и `results.tar.gz`. Для дальнейшей работы требуются доступ к проекту и действующий SSH-профиль `u3129`.

Из корня рабочего проекта TiAl в PowerShell выполнить

```powershell
python -B phase_reproduction/solvus_closure/atomistic/closure_runs.py resume
```

Команда считывает уже выданные идентификаторы, ожидает завершения, получает архивы, проверяет SHA-256, распаковку и кадры. Она заканчивает работу записью `slurm_accounting.csv`, `series_summary.csv` и `provenance.json` рядом с этим файлом. Команду можно снова запустить после прерывания. Последующий термодинамический анализ использует файлы из `series/<имя серии>/`.

Чтобы отдельно обновить состояние очереди и сохранить его одновременно на сервере и локально, выполнить

```powershell
python -B phase_reproduction/solvus_closure/atomistic/closure_runs.py checkpoint
```

Перед выключением ПК сохранён снимок `checkpoints/20261126T030240Z.json`. После перерыва `checkpoints/20261126T050450Z.json` подтвердил состояние `COMPLETED` у всех 36 заданий. Копии с теми же именами хранятся на UMT в `/home6/u3129/tial-closure-20261126/checkpoints/`. Итоговая копия снимка проверена по SHA-256. В снимках перечислены все Slurm ID, состояния, узлы и доступность локального архива на момент проверки.
