# Перевзвешивание по температуре и составу

Каждая оценка относится к одному размеру ячейки, свободным объёму и отношению осей, нулевому давлению и ограничению смещений `W < 0.40`. Для 768 и 1400 атомов доступны расчёты по отдельным исходным температурам и совместная оценка по четырём изотермам. Для 2304 атомов использована изотерма 1245 К. Составы указаны в ат.% Al. Для новых расчётов основной оценкой служат зонтичные окна. Независимая проверка из ранее рассчитанной изотермы 1273,15 К включает также её несмещённые траектории.

При смене шага прореживания с восьми кадров до четырёх температура совместной оценки меняется с 1243,77 до 1244,02 К для 768 атомов и с 1241,77 до 1242,05 К для 1400. Все 38 400 производственных кадров крупнейшей ячейки вошли в её отдельную оценку. [Проверка на 768 атомах](stride4_n768.json) · [Проверка на 1400 атомах](stride4_n1400.json) · [Расчёт на 2304 атомах](direct_1245_n2304.json).

## Относительные веса

Сначала MBAR определяет равновесные веса кадров при исходных \(T_0,\mu_0\), снимая смещение по порядку. Для другого поля и близкой температуры логарифм веса каждого кадра меняется на

\[
 -(\beta-\beta_0)(E-\mu_0 k)+\beta(\mu-\mu_0)k .
\]

Здесь \(k=N_{\rm Al}\), \(E\) — полная энергия MTP в эВ из колонки `E_eV`, а \(\mu\) — конфигурационное поле замены Ti на Al. Изменение температуры требует сохранённой энергии каждого кадра. Объёмная мера одинакова во всех состояниях при заданной механической постановке. Близость по температуре проверяется эффективной выборкой и сравнением независимых исходных изотерм. Файлы `1000_n288.json` и `1273_n*.json` служили для выбора полей. В частности, дальнее перевзвешивание 1000 → 1100 К для 288 атомов практически теряет перекрытие в фазах.

## Конгруэнтная вершина

Для фиксированного разделителя \(c\) между максимумами \(P(Q)\) определяется

\[
 D(T,\mu)=\ln P(Q>c)-\ln P(Q\le c)-\ln 4 .
\]

Множитель четыре учитывает четыре трансляционных варианта D0₁₉. В вершине конечной ячейки максимум \(D\) по полю касается нуля. Поэтому решаем одновременно \(D=0\) и \(\partial_\mu D=\beta(\langle k\rangle_2-\langle k\rangle_1)=0\) с отрицательной второй производной по полю. Равенство средних составов следует из уравнения максимума. Отдельными физическими проверками служат пики порядка, минимум между ними, рост барьера с размером и разность энергии между бассейнами. При совпадении составов и \(p=0\) величина \((\langle E-\mu k\rangle_\alpha-\langle E-\mu k\rangle_{\alpha_2})/N\) даёт оценку поглощаемой теплоты разупорядочения. Кинетический вклад классических ядер в разности сокращается.

В `vertex_bootstrap.py` якобиан вычисляется из разностей фазовых средних, дисперсий и ковариаций. В каждом блочном повторе заново подгоняются нормировки зонтиков и оба уравнения для температуры и поля. Временные блоки нарезаны отдельно в каждой траектории с учётом автокорреляции состава, порядка, объёма, осевого отношения и \(E-\mu_0k\). Записаны полученные корни, длины выборок и условные 95%-е интервалы. Эти интервалы относятся к данному \(N,c\), выбранному ансамблю и имеющимся траекториям. Сравнение временных половин и независимых изотерм дополнительно проверяет медленную динамику. Изменение \(c\) существенно влияет на малые ячейки, у которых разделяющий минимум неглубокий.

Для независимой проверки `congruent.py` максимизирует отношение бассейнов по полю и затем непосредственно находит ноль по температуре. `check_thermal.py` восстанавливает известную вершину дискретной модели с восемью микросостояниями и разными энергиями при одном составе и порядке. [Проверка знаков, единиц и весов](validation.json).

## Совместное использование нескольких температур

`pooled.py` подгоняет общие нормировки **всех** зонтиков всех включённых температур на сырых \((E,k,Q)\). Приведённый потенциал состояния \(j\) относительно общего невозмущённого ансамбля \((\beta_0,\mu_0)\) равен

\[
 (\beta_j-\beta_0)(E-\mu_0 k)+\beta_j\left[K_j(Q-q_j)^2/2-(\mu_j-\mu_0)k\right].
\]

Общие константы на состояние могут быть опущены. Результат объединения получается из перекрытия распределений в полном пространстве энергии, состава и порядка. Файл содержит матрицу вероятностей принадлежности кадров к другим температурам, число независимых временных блоков и повторную подгонку нормировок для каждой блочной выборки. Отдельные температуры анализируются также самостоятельно, чтобы видеть межсерийный разброс. Для одной температуры 1250 К на 288 атомах две реализации при сохранении всех кадров дали расхождение температуры вершины менее 0,00005 К. Работу многотемпературного оценивателя на известном распределении отдельно проверяет `check_thermal.py`.

## Воспроизведение

Из корня проекта, с NumPy и SciPy, можно вывести команды, рассчитать вершину по сохранённым траекториям и отдельно проверить временные половины. Полный и половинный анализы пишут в разные файлы.

```powershell
$py = 'blind_pilot/.venv-local/Scripts/python.exe'
$s = 'phase_reproduction/solvus_closure'
& $py "$s/check_thermal.py"
& $py "$s/thermal_cases.py" --show
& $py "$s/thermal_cases.py" direct_1245_n1400
& $py "$s/thermal_cases.py" direct_1245_n1400 --part early --draws 0
& $py "$s/thermal_cases.py" direct_1245_n1400 --part late --draws 0
```

Чтобы повторить проверку на 1400 атомах с вдвое большим числом кадров и теми же окнами, удобно прочитать пути к манифестам из основной оценки и передать их в `pooled.py`. Для 768 атомов используются `pooled_n768.json` и выходной файл `stride4_n768.json`.

```powershell
$fit = Get-Content "$s/analysis/thermal/pooled_n1400_all.json" -Raw | ConvertFrom-Json
$tables = $fit.manifests.ForEach({ Join-Path 'phase_reproduction' $_ })
& $py "$s/pooled.py" @tables --stride 4 --draws 0 --out "$s/analysis/thermal/stride4_n1400.json"
```
