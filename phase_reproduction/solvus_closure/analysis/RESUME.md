# Возобновление прямых изотерм

**Итог после возобновления.** Все 36 серий локально получены и проверены. Полная команда `--require-all` завершилась с кодом 0. Таблицы содержат 23 прямых изотермы и 46 записей по сторонам области упорядочения; численные результаты и утверждённые статусы описаны в [DIRECT_RESULTS.md](DIRECT_RESULTS.md).

После загрузки завершённых окон в `solvus_closure/atomistic/series` выполнить из корня TiAl в PowerShell:

~~~powershell
.\blind_pilot\.venv-local\Scripts\python.exe phase_reproduction/solvus_closure/analysis/resume_direct.py --status
.\blind_pilot\.venv-local\Scripts\python.exe phase_reproduction/solvus_closure/analysis/resume_direct.py --require-all
~~~

Программа сверяет полный список запусков с манифестом, кодом завершения и наличием траекторий и конечных состояний. Она обрабатывает локальные данные и не запускает задач на UMT. По окончании `--require-all` возвращает статус 2, если остались отсутствующие серии. Без этого аргумента можно обновить промежуточные таблицы по полным группам. Прерывание локального анализа допускает повтор команды. Сценарий повторно анализирует группу, если добавлено поле или отсутствует требуемая статистика, и заменяет файл изотермы после успешного завершения. На N≥768 используются 64 повторения по временным блокам и сравнение двух половин. Основная ветвь при 1225 K N768 использует все пять полей, ранняя версия с четырьмя сохранена в `control_T1225_N768_lr.json`.

**На момент прерывания** на N768 и N1400 знак максимума логарифма отношения весов при разделителе 0.47 надёжно положителен при 1225 К и отрицателен при 1250 К. Полные прямые трёхразмерные проверки в самой области замыкания требуют последующих загрузок. У 1100 K N768 Ti-богатая ветвь 17.943/23.011 ат.% Al и барьер 3.216 kBT; при 1225 K N1400 — 23.684/25.085 ат.% и 3.055 kBT. Добавленное Al-богатое поле N768 при 1225 K дало обратный разрыв 30.756/29.885 ат.% при поле 3.620708 эВ и барьер 0.848 kBT.

## Научная проверка после загрузки

* Составить прямую температурную скобку по `apex_temperature.json` для каждого N и разделителей 0.42, 0.47 и 0.50. Проверить положение максимума, локальный наклон, интервалы при переподгонке и временные половины. На N2304 доступна прямая 1245 К; одноточечный линейный прогноз имеет отдельный статус. Температурное перевзвешивание исходных энергий выполняет отдельный анализ в `thermal`.
* Для ветвей сверить `closure_summary.csv` и `fixed_cut_contacts.csv` с физическими модами, барьером (при каком критерии получен), фазовыми ESS, долей успешных повторов, разностью двух половин и данными другого размера. При максимуме веса составы в двух бассейнах математически совпадают, поэтому для порядка перехода дополнительно проверить разделение по Q и энергии и сравнение барьера при собственном температурном контакте каждого N.
* Доступные размеры, диапазон полей и поддержку каждого бассейна проверить до смены статуса. При независимом подтверждении составов и барьера на разных размерах добавить в `reviewed_status.json` соответствующую пару T/N/ветвь со значением `resolved`. Контакт одного размера остаётся `candidate`. Когда охваченная область полей заканчивается раньше предполагаемой ветви, выбрать `inadequate_coverage`; при отсутствии контакта в поддержанной данными области — `unresolved`. Повторить `summarize.py` после редактирования. Вновь полученные контакты по умолчанию попадают в таблицы со статусом `candidate`; программа не объявляет смену типа перехода автоматически.
* Оценить поправки на конечный размер по `size_scaling.json`, независимые полевые оценки по `subsets_*.json`, кинетику свободных стартов по `K0_*.json`, локальные домены по `terminal_*.json`. Для графиков 1245 К доступны `critical_order_profiles.csv` с локальной оценкой эффективной статистики. При расхождении разных расчётов привести диапазон и источники неопределённости в итоговом отчёте.
