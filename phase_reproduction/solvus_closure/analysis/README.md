# Прямые изотермы α–α₂

Каждый первичный профиль объединяет зонтичные траектории одной температуры, размера, интервала смещений и процедуры изменения ячейки. Равновесие относится к HCP-решётке с обменом Ti и Al, классическими смещениями, свободными объёмом и отношением осей при нулевом давлении. Поле \(\mu\) обозначает конфигурационную разность химических потенциалов. При загрузке проверяются температура траектории и полный набор производственных шагов.

Веса MBAR зависят от числа атомов Al \(k\) и свёрнутого параметра порядка \(Q=4(4\max_j n_j-k)/(3N)\), где \(n_j\) — заселённости четырёх подрешёток. Перевзвешивание по полю умножает массу состояния на \(\exp[(\mu-\mu_0)k/(k_BT)]\). На обеих сторонах области упорядочения программа независимо ищет равенство высот двух максимумов \(P(Q)\), фиксирует разделитель в их минимуме, затем вычисляет поле с \(P_{\rm high}/P_{\rm low}=4\). Множитель четыре учитывает четыре трансляционных варианта D0₁₉. Составы получают по средним \(k/N\) внутри каждого бассейна. На Al-богатой стороне разность \(x_{\rm high}-x_{\rm low}\) может быть отрицательной.

Для проверки конгруэнтной вершины вычисляется

\[
S_N(T;q_c)=\max_{\mu}\ln\frac{P_\mu(Q>q_c)}{4P_\mu(Q\le q_c)}.
\]

При внутреннем максимуме производная по полю обращается в нуль, поскольку она равна \(N(x_{\rm high}-x_{\rm low})/(k_BT)\). В двух достаточно разделённых структурных бассейнах этот максимум допускает совпадение составов при конечном различии порядка и энергии. Ноль \(S_N\) определяет конечносистемную температуру равных статистических весов на один вариант. Проверяются постоянные \(q_c=0.42,0.47,0.50\), положения минимумов, чувствительность к ширине сглаживания Q и к размеру системы. Численный ноль в одновершинном распределении зависит от условного разреза такого распределения.

В точке внутреннего максимума локальная оценка наклона равна \(N\Delta(u-\mu x)/(k_BT^2)\). Для \(u\) используются полные энергии MTP из тех же кадров. Эта производная обеспечивает локальную проверку интерполяции по температуре. Ошибки ветвей и \(S_N\) получают повторной подгонкой MBAR после выборки последовательных временных блоков независимо в каждой траектории. Неопределённость конгруэнтной температуры от статистики, выбора разделителя, размера и диапазона полей оценивается раздельно.

Файл `reproduce.py` содержит список манифестов и границ поиска для каждой изотермы. Например, из каталога анализа можно выполнить

~~~text
python reproduce.py T1245_N768 --bootstrap 64 --halves
python summarize.py
python apex_temperature.py
~~~

Компактная таблица ветвей сохраняется в `closure_summary.csv`, а интервалы прямых температур и локальные линейные оценки для каждой ячейки и разделителя — в `apex_temperature.json`. Поля `field_edge` и `inside_simulated_fields` показывают, поддержан ли экстремум прямой сеткой полей. Отдельные несмещённые старты анализирует `hysteresis.py`. Для медленно переключающихся цепочек намеренно заданное число стартов в каждом бассейне определяет только пропорции набора запусков.

`size_scaling.py` сопоставляет максимумы \(S_N\) при общей температуре в парах ячеек от 768 атомов. Объёмное преимущество упорядоченной фазы оценивается величиной \(k_BT(S_{N_2}-S_{N_1})/(N_2-N_1)\). Это устраняет постоянное по размеру слагаемое логарифма весов. Зависимость от формы и размера конечных ячеек может оставаться. Интервалы получают независимым выбором блочных повторений двух размеров.

`check_subsets.py` повторяет MBAR по независимым группам зонтиков каждого химического поля, вычисляя вес при общей \(\mu\) полного профиля. Малый эффективный размер выборки в одном из бассейнов ограничивает точность отдельной группы. `critical_profiles.py` экспортирует \(P(Q)\) и \(-\ln [P(Q)/\max P]\) при 1245 К. `terminal_order.py` сравнивает локальный порядок в заключительном состоянии каждого окна с 64 случайными перестановками внутри каждой кристаллографической подрешётки. Такой контроль сохраняет глобальные заселённости и выявляет дополнительные пространственные корреляции.
